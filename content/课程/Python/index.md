# Python 从入门到大神

黑马程序员「Python+AI 零基础入门到大神」全套课，共 185 集、51.6 小时。整门课切成 **71 个视频块**（每块 40–60 分钟），再按知识结构合成 **15 章**。

## 目录约定

```text
课程/Python/
└── 02-数据存储与运算/           ← 一章一个文件夹，前缀是章号
    ├── index.md                 ← 本章导读：知识点顺序表、检查点
    ├── 01-变量与赋值.md          ← 知识点笔记，前缀是阅读顺序
    ├── 02-数据类型与转换.md
    ├── …
    └── 精读长文/
        ├── 01-变量.md           ← 对应视频块的深读长文
        └── …
```

两条命名规则：

- **文件夹和文件都以两位数字开头**，数字就是顺序，不用猜。
- **名字写知识点，不写集号**：`04-字符串格式化.md`，不是 `第16讲.md`。
