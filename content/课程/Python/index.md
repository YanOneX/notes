# Python 从入门到大神

黑马程序员「Python+AI 零基础入门到大神」全套课，共 185 集、51.6 小时。整门课按知识结构切成 **71 个视频块**，每块 40–60 分钟；再由这些块合成 **15 篇复习笔记**——一篇对应一个章节，跨集但不跨章。

> **怎么用**：学习时读「精读长文」（跟着视频逐块展开）；复习时只读「复习笔记」（一页一章，扫一遍就能定位、合上能复述）。
