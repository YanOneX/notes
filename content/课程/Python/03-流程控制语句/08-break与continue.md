# break 与 continue

### 两个关键字

* **break**
* > **定义**：只能出现在循环内部的跳转语句，作用是结束整个循环、跳出循环。
* 写在循环外是语法错误；想在哪跳出就把 `break` 放在哪。
* 执行 `break` 后，`while ... else` / `for ... else` 中的 `else` 不执行，因为它不属于正常结束。

* **continue**
* > **定义**：只能出现在循环内部的跳转语句，作用是中断本次循环，直接进入下一次循环。
* 它不结束整个循环，只是跳过本轮剩下的语句回到循环开头。
* 不影响循环正常结束时 `else` 的执行。

* **分工**
* 两者都只服务循环，`while` 与 `for` 里都能用；区别只在走多远：`break` 走到循环外，`continue` 走回循环头。

| 关键字 | 允许出现的位置 | 作用 | 对 `while ... else` 的影响 |
| :--- | :--- | :--- | :--- |
| `break` | 只能在循环内 | 结束（跳出）整个循环 | `else` 里的代码不再执行 |
| `continue` | 只能在循环内 | 中断本次循环，直接进入下一次 | 不影响正常结束时的 `else` |

### 登录循环

* **需求与选型**
* 三组正确凭证：`admin` / `666888`，`张三` / `123456`，`涛哥` / `888666`，任一套命中即登录成功。
* 登录失败要继续提示重输、直到成功才结束，这是反复做同一件事，用循环。
* 失败次数不可预估、结束条件却明确，属于「次数未知、条件已知」，用 `while True` 而不是 `i < 10` 那种计数写法。

* **循环体的三步**
* 接收：`username = input("请输入用户名：")`、`password = input("请输入密码：")`，两行必须缩进进循环体。
* 校验：`if username == "" or password == "":` 提示不能为空并 `continue`；`""` 是空串，`" "` 是一个空格字符，不算空。
* 判断：三组账号各占一个分支，组内 `and`、组间 `elif`，全不匹配进 `else` 提示错误。
* 成功分支里写 `break`，三个成功分支都要加；漏掉某一组，用那组账号登录就退不出去。
* > **易错点**：两行 `input` 顶格写就落到 `while` 外面，`while True` 会变成疯狂空转、什么都不做的死循环。
* > **易错点**：空值判断用 `and` 会变成「两个同时为空才提示」，只漏一个照样往下走。

```python
while True:
username = input("请输入用户名：")
password = input("请输入密码：")
if username == "" or password == "":
print("输入的用户名和密码不能为空，请重新输入")
continue
if username == "admin" and password == "666888":
print("登录成功，进入到B站首页")
break
elif username == "张三" and password == "123456":
print("登录成功，进入到B站首页")
break
elif username == "涛哥" and password == "888666":
print("登录成功，进入到B站首页")
break
else:
print("用户名或密码错误，请重新输入")
```

### 猜数字

* **生成随机数**
* `import random` 导入模块，`random_number = random.randint(1, 100)` 生成 1 到 100 的随机整数，两端都包含。
* 随机数只能生成一次，必须写在循环外；写进循环体每轮都换数，永远猜不对。

* **猜的过程**
* `number = int(input("请输入一个数字："))`，`input` 返回字符串，不转 `int` 无法与整数比大小。
* 三分支：`number > random_number` 提示太大，`number < random_number` 提示太小，`else` 猜对。
* 猜对后要 `break` 跳出；改用 `continue` 只结束本轮，猜对了还继续让你猜，游戏永远结束不了。
* 循环里没有任何出口时，循环之后那行代码会变成灰色并提示「此代码不可到达」，这是循环没有出口的信号。
* 折半策略：每猜一次把范围砍一半，1~100 实际七次命中（50 → 75 → 85 → 93 → 97 → 95 → 96）。
