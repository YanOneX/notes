# for 与 range

### 遍历机制

* **for 循环**
* > **定义**：一种轮询遍历机制，对一批数据逐个处理，数据处理完循环自行结束。
* 语法 `for 元素 in 数据集:`；`for` 与 `in` 都是关键字，搭配固定，中间是自取的变量名，代表每次取出的那一个元素。
* 循环体缩进写在下面；数据集可以是字符串这类数据容器，字符串里的每个字符本身又是一个子字符串。
* 转多少次不取决于条件，而取决于数据集里有多少个元素。
* 流程：判断容器里还有没有元素 → 有就取出一个（容器随之少一个）→ 处理 → 回到判断；没有则结束。
* 判断发生在取之前，所以不会多取一个，取到最后一个处理完再判断就退出。

* **for...else**
* 循环正常结束后执行 `else` 里的逻辑；可选结构。
* 与 `if` 的 `else` 语义完全不同：`if` 的 `else` 是条件不成立时走这边，`for` 的 `else` 是循环顺顺当当走完后走这边。
* 项目开发里用得比较少，读别人代码时要认得。

* **与 while 的分工**
* 次数未知、只知道开始与结束的条件 → `while`。
* 遍历已知数据集，或次数明确可知 → `for`。

| 对比项 | while 循环 | for 循环 |
| :--- | :--- | :--- |
| 靠什么决定循环 | 条件表达式的布尔结果 | 数据集中还有没有元素 |
| 循环次数 | 事先未知，只知道开始与结束的条件 | 由数据集元素的个数决定 |
| 典型场景 | 条件满足就一直做下去 | 遍历已知数据集、已知次数的循环 |
| 要提防的 | 条件恒为 `True` 会变成无限循环 | 遍历完自动退出，不用写退出条件 |

### range 数字序列

* **range**
* > **定义**：按指定规则生成数字序列的数据集生成器，产出的序列直接交给 `for` 遍历。
* 一个参数 `range(5)`：从 0 开始、到 5 结束，不含 5。
* 两个参数 `range(2, 8)`：第一个是 start、第二个是 end，仍不含 end。
* 三个参数 `range(0, 10, 2)`：前两个是 start 与 end，第三个是步长 step，默认 1，写 2 就每次加 2。

* **包前不包后**
* 三种写法的结束值一律不包含：要 1 到 100 这 100 个数，必须写 `range(1, 101)`。
* > **易错点**：写成 `range(1, 100)` 只有 99 个数，100 被漏掉。

| 写法 | 含义 | 生成的序列 |
| :--- | :--- | :--- |
| `range(5)` | 从 0 开始，到 5 结束（不含 5） | 0 1 2 3 4 |
| `range(2, 8)` | 从 2 开始，到 8 结束（不含 8） | 2 3 4 5 6 7 |
| `range(0, 10, 2)` | 从 0 开始，步长 2，到 10 结束（不含 10） | 0 2 4 6 8 |

### 求和案例

* **1~100 的奇数之和**
* 骨架：`total = 0`，`for i in range(1, 101):`，`if i % 2 == 1: total += i`，结果 2500。
* 简化：把步长写成 `range(1, 101, 2)`，序列本身只含奇数，循环体直接 `total += i`，结果仍是 2500。
* > **易错点**：删掉 `if` 却忘了改步长，加进去的是 1 到 100 全部 100 个数，结果是 5050。

* **100~500 的 3 的倍数之和**
* 数据集写 `range(100, 501)`，501 才能把 500 包进来；不能写成 `range(501)`，那会从 0 开始把 0 到 99 也带上。
* 判断 `i % 3 == 0`，循环体累加，结果 39900。
* 两个求和案例共用同一骨架：`range` 造数据、`for` 逐个取出、`if` 筛选、`total += i` 累加、最后输出。
