# while 循环

### 语法与流程

* **while 循环**
* > **定义**：循环就是重复执行某件事；`while` 靠条件表达式的布尔结果决定是否再执行一遍循环体。
* 语法 `while 条件表达式:`，下面缩进写循环体，缩进了才属于 `while`。
* 流程：判断条件 → 为 `True` 执行循环体 → 回到条件再判断；为 `False` 结束循环往下走。
* 循环体执行完是回到条件处，而不是继续往下，这是它与顺序执行的根本区别。
* 循环次数完全由条件表达式决定。

* **死循环（无限循环）**
* 条件恒为 `True` 时循环停不下来，称为死循环，非常消耗系统性能。
* 现象：控制台一直刷、运行按钮一直是绿点，只能手动点停止。

* **while...else**
* 在整段循环后追加 `else:`，其中逻辑在条件为 `False`、循环正常结束时执行。
* 可选结构，要不要写看需求；循环被 `break` 中途打断时，`else` 里的代码不执行。

### 计数与累加

* **打印十遍**
* `i = 0`，`while i < 10:`，循环体里打印并执行 `i += 1`（等价 `i = i + 1`）。
* i 从 0 走到 9 共十遍；第十遍做完 i 变 10，`10 < 10` 不成立，循环结束并执行 `else`。
* > **易错点**：漏掉 `i += 1`，i 恒为 0、条件恒成立，立刻变成死循环。

* **1~100 偶数累加**
* `total = 0` 记累加和，`i = 1` 起步，条件写 `i <= 100`——两头都要包含。
* 循环体先 `if i % 2 == 0:` 再 `total += i`；无论奇偶，`i += 1` 都要执行。
* 结果为 2550；最后的 `print` 顶格写在循环外，循环结束后才执行。
* > **易错点**：`i += 1` 写进 `if` 里，碰到奇数就不加一，循环卡死在原地变成死循环。

* **循环套分支**
* 循环体里可以放 `if`，偶数累加就是最小例子：外层重复、内层判断。
