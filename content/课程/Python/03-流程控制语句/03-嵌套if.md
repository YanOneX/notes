# 嵌套 if

### 嵌套与占位

* **if 嵌套（nested if）**
* > **定义**：在一个 `if` 的代码块里再写 `if`，外层判断通过后才轮到内层判断。
* 两层各管一件事：外层判「前提是否成立」，内层在成立的范围内继续细分。
* 嵌套层数本身没有限制，真正的限制是可读性。

* **pass 空语句**
* > **定义**：`pass` 是不执行任何操作的空语句，只负责占住语法位置。
* `if` 条件成立后必须跟代码块，逻辑还没想好时先用 `pass` 撑住结构，语法才不报错。

### 缩进与配对

* **缩进即层级**
* 同一套结构里的 `if`、`elif`、`else` 缩进必须完全一致；不同套之间靠缩进拉开层次，内层整体比外层多缩一层。
* `else` 永远属于和它左对齐的那个 `if`，顺着同一列往上看就能确定它兜的是哪一段。
* > **易错点**：`else` 缩进退一格，就会从外层的兜底变成内层 `if` 的兜底，逻辑立刻改味。

* **调试验证分支走向**
* 在第一次做条件判断的那一行打断点：鼠标移到行号左边点一下出现圆点，再点一下取消；用调试模式运行而不是普通运行。
* 程序停在断点后按 `F8` 单步，变量面板能看到各变量的值与类型，蓝色高亮停在哪一行就说明走到哪一行。
* 分支多时光看输出难以确认走了哪条路，单步能直接看见是进入内层还是落进 `else`。

### 三角形案例

* **构成条件**
* 任意两边之和大于第三边，写成 `a + b > c and a + c > b and b + c > a`，三个不等式同时成立。
* 三组两两组合缺一不可，只写一组时「任意」两个字就落空。
* > **易错点**：漏掉一组不等式不会报错，只会在某些输入下悄悄给出错误答案。

* **形状判定**
* 等边：三条边都相等，`a == b and b == c`，用 `and`。
* 等腰：任意两条边相等，`a == b or b == c or a == c`，三种组合用 `or` 串起来。
* 普通：前两支都不成立，三边互不相等，直接 `else`。
* 外层 `if...else` 管「能不能构成」，内层 `if...elif...else` 管「是什么形状」，两层互不干扰。

```python
a = int(input("请输入第一个边的边长："))
b = int(input("请输入第二个边的边长："))
c = int(input("请输入第三个边的边长："))

if a + b > c and a + c > b and b + c > a:
if a == b and b == c:
print(f"三条边长 {a}、{b}、{c} 构成等边三角形")
elif a == b or b == c or a == c:
print(f"三条边长 {a}、{b}、{c} 构成等腰三角形")
else:
print(f"三条边长 {a}、{b}、{c} 构成普通三角形")
else:
print(f"三条边长 {a}、{b}、{c} 不能构成三角形")
```

* **测试路径**
* 输入 10、5、3：`5 + 3 = 8` 小于 10，外层不成立，直接输出「不能构成三角形」。
* 输入 18、15、13：三组不等式都成立，进入内层；三边两两不等，落进内层 `else`，输出普通三角形。
* 输入 18、18、19：外层成立，内层第一个条件不成立，`elif` 命中，输出等腰三角形，后面的 `else` 不再执行。

### 注释

* **单行注释**
* 用 `#` 注释该行内容，`#` 可以缀在任意一行代码的末尾。
* 编辑器里用 `Ctrl + /` 可以批量加上或取消行首的 `#`。

* **三引号注释**
* 用三引号包住整段文字，可跨很多行，不必每行都加井号。
* 三引号原本是定义字符串的第三种方式；前面没有变量接住，它就只是一段没人用的字符串，效果等同注释。
* 有变量接住时它就是真正的字符串，所以三引号注释通常整段放在语句位置，不能缀在代码行尾。
