# 第 03 章 流程控制语句

对应视频 **P22–P35**（5 个视频块，约 3.8 小时）。这一章解决一件事：**让代码按你的意图决定走哪条路、走几遍**。

## 学习顺序

按编号读，后面的篇目默认你读过前面的：

| 顺序 | 知识点 | 一句话 | 读多久 |

## 本章检查点

合上笔记，能不看资料写出下面这段，就算过关：

```python
total = 0
for i in range(1, 101):
    if i % 3 == 0:
        continue
    if total > 2000:
        break
    total += i
print(total)
```

说不清「`break` 跳的是哪一层」「`continue` 之后本轮剩下的语句还执行吗」，回头看 07 和 08。
