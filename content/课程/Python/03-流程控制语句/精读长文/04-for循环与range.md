# 挨个处理一批数据：for 循环与嵌套循环

## 为什么有了 while 还要有 for

while 循环是靠条件表达式决定要不要进入下一次循环的。条件表达式算出来是一个布尔值，为 True 就代表条件成立，继续执行一遍循环体当中的语句；为 False 就代表该退出了，循环到此为止。所以写 while 的时候，脑子里想的始终是那个条件——它到底成不成立。

这带来一个很实际的问题：如果条件表达式的结果一直是 True，while 就进入了无限循环，一直转下去，谁也拦不住它。这不是 while 的缺陷，是它的本性，它本来就是按"条件"办事的。

for 循环换了一套思路。它本质上是一种轮询遍历机制：对一批内容逐个处理，这批内容处理完了，循环自己就结束了。也就是说，for 循环到底转多少次，不取决于你写的某个条件，而取决于这批数据里到底有多少个数据。

我拿箱子举个例子。这儿有一个箱子，里面装着一箱乒乓球。需求是把箱子里面的球逐个编号。那我要做的动作就是：从箱子里拿出一个球，编上号，放到外面；再从里面拿一个，编号，放到外面；再拿一个……直到箱子空了，球都编完号了，这个任务也就结束了，这次循环也就结束了。

你看，我从头到尾没有问过"条件还成不成立"，我只关心箱子里还有没有球。这就是 for 和 while 最根本的差别。

> **结论**：while 盯的是条件，for 盯的是数据。条件还在就继续，数据没了就收工。

## for 循环怎么转起来

for 循环的执行流程，按顺序是这么几步。

开始循环之后，它先去判断容器当中是否还有要处理的元素。有，就取出其中的一个来处理。注意，每一次只取一个；而且取出这一个之后，容器里就少一个。处理完这个元素，它再回到容器里看一眼：还有没有？有，就再取下一个，再处理。如此往复。等到容器里的元素都被取完了，没有可处理的了，循环结束。

```text
 开始
  │
  ▼
 容器里还有要处理的元素吗？ ──没有──▶ 循环结束
  │
  │有
  ▼
 取出一个元素
  │
  ▼
 处理这个元素
  │
  └───────────────▶ 回到判断
```

图里那条回到判断的箭头是关键：每处理完一个元素，都要重新问一遍"还有吗"，问出"没有"才肯退出。

这里有个细节值得盯一下：判断发生在取之前，而不是取之后。所以它不会多取一个，也不会因为"取空了"而出问题——取到最后一个、处理完、回去判断、发现没有了，退出。整个节奏就是"判断—取—处理—判断"，干净利落。

## 语法：for、in 和那个可选的 else

Python 里 for 循环的骨架长这样：

```python
for 元素 in 待处理的数据集:
    循环体代码
else:
    循环正常结束时执行的代码
```

`for` 是关键字，`in` 也是关键字，`for ... in ...` 这个搭配是固定的，中间的"元素"是你自己起的变量名。

先说 `in` 后面这个待处理的数据集。前面讲过，for 是对一批内容逐个处理，这个数据集就是一个大容器，容器里装着一项一项待处理的数据。它决定了 for 要去轮询遍历哪一个数据集。

再说 `for` 和 `in` 中间那个名字。它是一个变量名，代表我们从数据集里每一次取出来的那一个元素。for 遍历的时候一次只取一项，取出来就放进这个变量里，于是循环体里就能拿着它做事了。

`for` 下面缩进的那一段就是循环体。拿到第一个元素，在循环体里处理完；回过头取第二个，再处理；第三个、第四个……直到数据集里所有元素都处理完，整个循环结束。

结尾的 `else` 是可选的，可以有也可以没有。它的含义是：循环正常结束时，执行它里面的逻辑。

> **注意**：`else` 挂在 for 上的语义，和挂在 if 上的完全不是一回事。if 的 else 是"条件不成立时走这边"，for 的 else 是"循环顺顺当当走完了，再走这边"。项目开发里这个结构用得比较少，但语法上它就在那儿，读别人的代码时得认得。

## 拿一个字符串练手

需求很简单：遍历 `hello Python` 这个字符串。

先得建立一个认识：字符串也是一种数据集，或者叫数据容器，里面存的就是一个一个的字符。`hello Python` 拆开看，`h`、`e`、`l`、`l`、`o`、空格、`P`、`y`、`t`、`h`、`o`、`n`，每一个都是一个字符，而每一个字符本身又是一个子字符串。

所以拿字符串给 for 练手正合适：它天然就是"一批数据"。

这次让字符串从键盘输入进来，输入什么就遍历什么：

```python
msg = input("请输入需要遍历的字符串：")

for s in msg:
    # s 表示遍历出来的元素，msg 表示需要遍历的数据
    print(f"遍历出来的元素是：{s}")
else:
    print("遍历结束")
```

`msg` 接住输入的字符串；`for s in msg` 让 for 把字符一个一个取出来放进 `s`；循环体里把它打印出来；循环走完，`else` 里的"遍历结束"再补一句。

运行时输入 `人生苦短,我用Python~`，控制台会一个字符一行地往下吐：人、生、苦、短、逗号、我、用、`P`、`y`、`t`、`h`、`o`、`n`、波浪线。为什么一行一个？因为 `print` 默认输出就带换行——这一点在打印长方形那节会变成一个必须处理的坑，先记住。

用调试模式一步步跟一遍更清楚。断点打在前面的输入语句上，然后单步走：

- 第一圈，`s` 的值是"人"，循环体把"人"输出到控制台；
- 第二圈，`s` 是"生"；
- 接着是"苦""短"、逗号、"我""用"，再往后是 `P`、`y`、`t`、`h`、`o`、`n`；
- 最后一圈，`s` 是末尾那个波浪线 `~`。

波浪线输出完，`msg` 这个容器里已经没有需要遍历的字符了，循环退出，转去执行 `else` 当中的逻辑，最后打出"遍历结束"。

> **结论**：for 不需要你告诉它什么时候停，它把数据集走空了自己就停。这就是"轮询遍历机制"这几个字的实际手感。

## for 和 while 各自守哪摊

有了 for 循环，while 循环是不是就可以不用了？并不是。它们各自有各自的应用场景。

while 通过条件来控制循环的次数，只要满足某个条件，它就可以一直循环下去，循环次数是未知的，你只知道循环开始和结束的条件是什么。所以关注点在"条件"上——达到条件就循环，条件不成立就退出，这种活交给 while。

for 主要针对一个已知的数据集做遍历，或者你已经明确知道循环次数。它的关键动作是把数据集当中的每一个元素都过一遍。所以只要是"遍历数据集"或者"已知次数的循环"，for 就是顺手的那个。

| 对比项 | while 循环 | for 循环 |
| :--- | :--- | :--- |
| 靠什么决定循环 | 条件表达式的布尔结果 | 待遍历数据集里还有没有元素 |
| 循环次数 | 事先未知，只知道开始与结束的条件 | 由数据集元素的个数决定 |
| 典型场景 | 条件满足就一直做下去 | 遍历已知数据集、已知次数的循环 |
| 要提防的 | 条件恒为 True 会变成无限循环 | 遍历完自动退出，不用你写退出条件 |

一句话记：知道"做到什么条件为止"，用 while；知道"要把这批东西过一遍"或者"就转这么多次"，用 for。

## range：造一串数字出来

接下来两个案例都要用到"1 到 100 之间的所有整数"这样的数据集。难道要把 100 个数一个一个罗列在 `in` 后面？那要算 1 到 1000 呢，写 1000 个数？显然不合理。

真正要先解决的是：怎么拿到指定范围的数据集。Python 给的答案是 `range` 语句。它的作用是根据指定的规则生成数字序列——说白了就是个数字生成器，给你造出一组符合规则的数据，也就是一个数据集。有了它，再交给 for 去遍历，两件事就接上了。

它有三种常见用法。

第一种，括号里只写一个数：

```python
range(5)        # 0 1 2 3 4
```

它生成从 0 开始、到 5 结束的数字序列，但不包含 5 本身。所以想拿到 0 到 5，得写 `range(6)`。

第二种，括号里写两个数，用逗号分隔：

```python
range(2, 8)     # 2 3 4 5 6 7
```

第一个数是 start，从哪儿开始；第二个数是 end，到哪儿结束。同样不包含结束的那个数。

第三种，三个数：

```python
range(0, 10, 2) # 0 2 4 6 8
```

前两个还是 start 和 end，多出来的第三个是 step，步长。步长说的是生成下一个数的时候加几：默认加 1，写成 2 就每次加 2，于是 0、2、4、6、8，隔一个取一个，同样不包含 10。

> **易错点**：三种用法的结束值一律"包前不包后"。想要 1 到 100 这 100 个数，写 `range(1, 101)`；写成 `range(1, 100)` 就只有 99 个数，100 被漏掉了。

| 写法 | 含义 | 生成的序列 |
| :--- | :--- | :--- |
| `range(5)` | 从 0 开始，到 5 结束（不含 5） | 0 1 2 3 4 |
| `range(2, 8)` | 从 2 开始，到 8 结束（不含 8） | 2 3 4 5 6 7 |
| `range(0, 10, 2)` | 从 0 开始，步长 2，到 10 结束（不含 10） | 0 2 4 6 8 |

## 案例一：1 到 100 的奇数之和

需求：计算 1 到 100 之间所有奇数之和。

先想数据集。要算 1 到 100 的奇数之和，首先得拿到 1 到 100 这 100 个数，而它们正好可以交给 `range` 生成，不用手写。

第一种写法：用一个变量记录累加之和，初值 0；for 遍历 1 到 100；循环体里判断是不是奇数，是就累加。

```python
total = 0

for i in range(1, 101):
    if i % 2 == 1:
        total += i

print("1~100之间所有奇数的累加之和是：", total)
```

`range(1, 101)` 里写 101 是为了把 100 包进来。也可以写成 `range(101)`，那种写法从 0 开始，但 0 加不加进 `total` 都不影响结果。

奇数怎么判断？一个数对 2 取余，余数是 1 就是奇数，所以判断条件写成 `i % 2 == 1`。是奇数就 `total += i`；不是就什么也不做，直接去遍历下一个元素。

跑一下，结果是 2500。

那这段代码还有没有简化的空间？有，而且简化的位置就在 `range` 上。

`if` 在这里的唯一作用是把偶数筛掉。那能不能让 `range` 干脆只生成奇数，从源头上就不用筛？可以，用第三种用法，把步长设成 2：

```python
total = 0

for i in range(1, 101, 2):
    total += i

print("1~100之间所有奇数的累加之和是：", total)
```

从 1 开始，每次加 2：1、3、5、7……一直到 99，整个序列里全是奇数，循环体里只管累加，一句判断都不用写。结果还是 2500。

> **易错点**：可别顺手把 `if` 删了却忘了改步长。`range(1, 101)` 配"直接累加"，加进去的是 1 到 100 全部 100 个数，结果是 5050，不是 2500。简化能成立，靠的是"`range` 只生成奇数"这个前提，不是"`if` 可有可无"。

## 案例二：100 到 500 之间 3 的倍数之和

需求：计算 100 到 500 之间所有 3 的倍数的数字之和。跟案例一是一个套路，改两个地方就行。

数据集变了，得用两个参数的写法：`range(100, 501)`，501 是为了把 500 包进来。这里不能再用只写一个数的形式——那种写法固定从 0 开始，会把 0 到 99 也一并带进来。

判断条件从"是不是奇数"换成"是不是 3 的倍数"。一个数能被 3 整除，它就是 3 的倍数，写成 `i % 3 == 0`。

```python
total = 0

for i in range(100, 501):
    if i % 3 == 0:
        total += i

print("100~500之间所有3的倍数的累加之和是：", total)
```

跑一下，结果是 39900。

这两个案例用的是同一个骨架：造数据集（`range`）、遍历（`for`）、循环体里判断（`if`）、累加（`total += i`）、最后输出。`range` 负责"有数据可遍历"，`for` 负责"一个一个取出来"，分工很清楚。

## 嵌套循环：循环体里再套一个循环

while 和 for 的核心语法都清楚了，再看循环的高级用法：嵌套循环。

所谓嵌套循环，指的是在一个循环语句的循环体里，又编写了一个循环语句。以 for 为例，骨架是这样的：

```python
for 元素1 in 数据集1:
    代码一
    代码二
    for 元素2 in 数据集2:
        代码三
        代码四
```

外层那个 for 遍历数据集 1，它下面缩进的所有内容都是它的循环体——包括代码一、代码二，也包括里面那个完整的 for。里面这个 for 又遍历数据集 2，它下面缩进的代码三是它的循环体。外面这层叫外层循环，里面这层叫内层循环。

执行流程怎么捋？一个很好用的办法是：先把外层循环忘掉，只盯着内层看。内层就是一个普通的 for，它把数据集 2 里的元素一个一个取出来处理，循环多少次取决于数据集 2 里有多少个元素。这一步想明白了，再把外层加回来。

加回来之后是这样的：外层每取出一个元素，就执行一遍自己的循环体；而循环体里包含内层循环，所以内层要完整地跑一轮。假设数据集 2 里有 N 个元素，那么外层转一次，内层就转 N 次。

```text
外层第 1 个元素
    └─ 内层把数据集 2 走完一遍（N 次）
外层第 2 个元素
    └─ 内层再把数据集 2 走完一遍（N 次）
外层第 3 个元素
    └─ 内层又走一遍（N 次）
...
外层元素取完 → 整个嵌套循环结束
```

读这张图只要盯住一件事：内层的"走完一遍"是外层每转一次都要重来一遍的，不是只走一次。

这事儿跟钟表很像。分针走一小格，秒针得转一整圈；分针再走一小格，秒针又得转一整圈。分针就是外层循环，秒针就是内层循环。分针慢悠悠地挪，秒针一圈一圈地跟着转——外层走一步，内层跑全程。

## 用星号打印一个长方形

需求：打印一个长度为 M、宽度为 N 的长方形。M 和 N 不固定，由用户从键盘输入；长方形用星号拼，长度是 M 就一行打印 M 个星号，宽度是 N 就打印 N 行。

比如长度 10、宽度 5，输出就是 5 行、每行 10 个星号。

这个需求看着是一整块，拆开只有两步：先搞定"一行星号怎么打"，再搞定"这一行重复多少遍"。

一行有多少个星号，取决于长度 M。所以先用一个 for 循环 M 次，每次打印一个星号：

```python
m = int(input("请输入长方形的长度："))
n = int(input("请输入长方形的宽度："))

for i in range(m):
    print("*")
```

`input` 拿回来的永远是字符串，所以要套一层 `int()` 转成整数，否则 `range(m)` 用不了。

`range(m)` 只传一个数，生成 0 到 m-1，一共 m 个，正好循环 m 次。这里的 `i` 其实用不上——我们不需要对 0、1、2 这些值做任何处理，只是想借这个序列把"打印一个星号"这个动作重复 m 次。

> **提示**：写第二行输入时不必手打，把光标放在那一行上按 `Ctrl+D` 可以整行复制。另外，光标停在行中间时直接回车，会把后半行推到新的一行；想在任何位置直接新起一行，按 `Shift+Enter`。

跑一下，输入长度 10、宽度 5，出来的是十个星号，但一个星号一行，整整十行。预期是一行星号，实际是十行。

原因在 `print`：它默认自带换行，每执行一次就输出到新的一行。循环十次，就是十行。

> **易错点**：`print` 的换行不是"顺便"加的，是它的默认行为。凡是想让多次 `print` 挤在同一行，都必须显式把这个换行去掉。

办法是给 `print` 指定 `end` 参数：

```python
print("*", end="")
```

`end` 表示这次输出以什么结束。它的默认值是 `"\n"`，也就是换行符——前面讲字符串时提到的那个转义字符。把 `end` 设成空字符串，就等于什么都不加，下一次 `print` 接着往同一行写。

```python
for i in range(m):
    print("*", end="")
```

再跑，十个星号整整齐齐排在一行。

`end` 里放什么，输出就以什么收尾。想让星号之间空开两个空格，写 `end="  "` 就行，每个星号后面跟两个空格——这个灵活性后面还要用到，也是下一个坑的来源。

一行搞定了，接下来是行数。有多少行取决于宽度 N，所以外面再套一个循环，转 N 次，每次输出一整行：

```python
for j in range(n):
    for i in range(m):
        print("*", end="")
```

外层的循环变量原来也写的 `i`，跟内层撞名了，改一个就行，换成 `j`。

这两个循环各管一件事：外层 `range(n)` 控制行，转 N 次就是 N 行；内层 `range(m)` 控制列，转 M 次就是一行 M 个星号。

但这么跑出来，所有星号全挤在一行里了。因为 `end` 里放的不是换行符——不管是空字符串还是两个空格，它只负责"这次输出后面跟什么"，不会给你换行；内层循环结束之后，外层直接进入下一轮，接着往同一行写。

缺的是"一行结束换行"这个动作。外层每转一次，就该换一行。最省事的做法是：内层循环结束后，调用一次不带任何内容的 `print()`。

```python
for j in range(n):
    for i in range(m):
        print("*", end="")
    print()
```

空 `print()` 什么都不输出，但它自带换行，正好给这一行收尾。

> **提示**：这里的缩进就是全部逻辑。`print()` 缩进到内层循环里，就变成每打一个星号换一行；跟内层循环平级，才是每打完一行换一次。

完整代码：

```python
# 接收键盘录入
m = int(input("请输入长方形的长度："))
n = int(input("请输入长方形的宽度："))

# 打印长方形
for j in range(n):
    for i in range(m):
        print("*", end="")
    print()
```

输入 15 和 5，得到的就是长度 15、宽度 5 的长方形。

用调试模式把嵌套的过程跟一遍，输入长度 6、宽度 3：

- 外层第一次，取到第一个元素，进入循环体，内层开始跑：内层第 1、2、3、4、5、6 次，打印 6 个星号，空 `print()` 换行；

- 外层第三次，内层再跑 6 次，出来第三行；

外层转一次、内层转一圈，跟分针和秒针一个节奏。
