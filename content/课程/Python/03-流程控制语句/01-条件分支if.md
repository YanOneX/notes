# 条件分支 if

### 语法与缩进

* **if 条件判断**
* > **定义**：只有在满足指定条件时才执行对应代码块的分支语句；条件不成立时整块跳过，程序继续往下走。
* 结构固定为三行：`if 判断条件:`，换行后缩进写「条件成立时要执行的代码」。
* 条件必须能算出布尔值：`True` 表示成立、执行代码块；`False` 表示不成立、一行都不执行。
* 条件后面必须跟英文冒号，中文输入法打出的全角冒号不算，漏写直接报语法错误。
* 代码块必须缩进；缩进几个空格语法上都成立，规范建议统一 4 个空格，编辑器按 Tab 默认转成 4 个空格。
* > **易错点**：同一代码块内各行的缩进量必须完全一致；某行多缩进一格，解释器会把它当成上一行语句的子语句，直接报缩进错误。

* **代码块（code block）**
* > **定义**：`if` 连同它下面缩进的那几行代码，整体构成一个独立的执行单元。
* 判断某行归谁管只看缩进，不看离得近不近：顶格写的语句不属于 `if`，条件成立与否都照常执行。
* 缩进同时表达层级：往里缩一层就落进上一层的地盘，多层嵌套也照此读。

* **单分支执行路径**
* 执行到 `if` 行先算条件：成立就执行块内全部语句，再继续往下；不成立就整块跳过，同样继续往下。
* 示例：`score = 700` 时 `if score > 680:` 里的欢迎词会输出；改成 `score = 600` 后块内两句都不输出，而顶格写在块外的横线照常输出。

### 双分支 if-else

* **if...else**
* > **定义**：为「条件成立」和「条件不成立」各准备一条出口的双分支结构，二者必走其一。
* `else` 后面不写任何条件，只跟一个冒号；`else` 下面的代码同样要缩进。
* 走到分岔处只走一条路：成立进 `if` 块，不成立进 `else` 块，走完合流继续往下。
* 结果只有两种可能时用它；反面情况交给 `else` 兜住，不必再写一个 `if` 把条件反过来问一遍。
* > **易错点**：`else` 不写条件但冒号不能漏；给 `else` 加上条件，它就不再是 `else`。

* **条件组合：and 与 or**
* `and` 两侧都为 `True` 整体才为 `True`，任一侧为 `False` 结果即为 `False`。
* `or` 只要有一侧为 `True` 整体即为 `True`，两侧都假才为 `False`。
* `and` 的优先级高于 `or`；用括号把「这是一整段条件」圈出来，结果不变而层次更清楚。
* `!=` 表示不等于，用来表达「这一项不对」。

* **登录校验**
* 正确账号 `18888888888`、正确密码 `666888`，先用变量存好再比较。
* 成功条件写成 `account == ok_account and password == ok_password`：账号对并且密码对。
* 失败条件写成 `account != ok_account or password != ok_password`：任意一项错就算失败。
* 初版用两个并列的 `if` 分别判成功与失败，能跑通但多算一次；改成 `if...else` 后第二个 `if` 整段删掉，判断由两次降为一次。

* **闰年判定**
* 非整百年份：能被 4 整除是闰年，不能被 4 整除是平年。
* 整百年份：能被 400 整除是闰年，否则是平年；1900 能被 4 整除却仍是平年，这条规则专门拦它。
* 合并条件写成 `(year % 100 != 0 and year % 4 == 0) or (year % 400 == 0)`，两段是「或者」关系。
* `year % 400 == 0` 已隐含该年是整百年份，不必再补 `year % 100 == 0`。
* 年份先转换：`year = int(input("请输入需要判定的年份："))`，再做取余。
* 验证：2025 平年、1900 平年、2004 闰年、2400 闰年。
* > **易错点**：`input()` 的返回值永远是字符串，直接拿去做 `%` 运算会报类型错误。
