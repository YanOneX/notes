# 多分支 elif

### 结构与执行

* **if...elif...else**
* > **定义**：在一条判断链上挂多个条件的分支结构，`elif` 是 `else if` 的简写，分支数量不再受两条限制。
* 结构：`if 条件一:` 起头，后面用任意多个 `elif` 追加条件，最后可跟一个 `else:`。
* `elif` 可以出现多次，业务有几个分支就挂几个；`else` 可有可无，写了必须放在最后，后面不能再接 `elif`。
* `if`、`elif`、`else` 必须顶格左对齐、处在同一列，才属于同一套结构。
* > **易错点**：在 `if` 代码块里回车后光标自动缩进，顺手写下的 `elif` 会变成 `if` 内部的语句，语法直接报错。

* **只走第一条成立的分支**
* 条件从上往下依次判断，问到第一个成立的就执行该分支代码，执行完整条判断链立即结束。
* 前面某条成立后，后面的 `elif` 与 `else` 条件不再计算、代码也不再执行。
* 全部条件都不成立才落进 `else`；没有 `else` 时这一轮什么也不做。
* 这是「多分支」与「多个独立 `if`」的区别：前者每次只走一条路，后者每个 `if` 都会各自判断。

* **顺序即优先级**
* 越靠前的条件越先被问，也越容易把后面的情况「吃掉」，`elif` 的排列顺序不能随手摆。
* 三个注意点：`elif` 可写多个；`else` 可省但只能放最后；判断从上往下、前面成立则后面连条件都不再算。

| 注意点 | 具体说法 |
| :--- | :--- |
| `elif` 的数量 | 可写多个，有几个分支就挂几个 |
| `else` 的位置 | 可有可无；写了必须放最后，后面不能再接 `elif` |
| 判断顺序 | 从上往下，前面成立则后面不再判断与执行 |

### 三分支与多套凭证

* **正数、负数与零**
* `number = int(input("输入数字："))`，先转整数再比大小。
* `number > 0` 打印正数，`elif number < 0` 打印负数，`else` 打印零。
* 输入 5 走第一支，输入 -1 走 `elif`，输入 0 落进 `else`，三条路各走一次。
* `if...else` 只有两个出口，接不住第三种情况；分支超过两条就得换多分支结构。

* **三套账号登录**
* 三组合法凭证：`admin` / `666888`，`root` / `547527`，`张三` / `123456`，命中任意一组即成功。
* 每组内部用 `and` 连接用户名与密码，三组之间用 `elif` 串联，全不匹配才进 `else` 提示错误。
* 给三句成功提示加上不同编号，便于确认实际跑的是哪一条分支。
* > **易错点**：组内写成 `or` 会变成「用户名对就行，或密码对就行」，只输对一半也能登录。
