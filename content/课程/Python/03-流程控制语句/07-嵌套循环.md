# 嵌套循环

### 结构与执行

* **嵌套循环（nested loop）**
* > **定义**：在一个循环的循环体里再写一个循环，外面一层叫外层循环，里面一层叫内层循环。
* 外层每取出一个元素就执行一遍自己的循环体，而循环体里含内层循环，所以内层要完整跑一轮。
* 数据集 2 有 N 个元素时，外层转一次内层就转 N 次，总执行次数是两层次数的乘积。
* 类比钟表：分针走一小格是外层走一步，秒针转一整圈是内层跑完全程。

* **分析套路**
* 先忘掉外层只看内层：内层就是一个普通循环，转几次由它自己的数据集决定。
* 再把外层加回来：外层负责「重复几遍」，内层负责「每一遍里做什么」。

### 打印长方形

* **一行怎么打**
* `m = int(input("请输入长方形的长度："))`、`n = int(input("请输入长方形的宽度："))`；`input()` 返回字符串，必须 `int()` 转换后才能给 `range` 用。
* 内层 `for i in range(m):` 配合 `print("*", end="")`：`range(m)` 生成 0 到 m-1 共 m 个数，正好重复 m 次。
* `print` 默认自带换行，`end` 参数指定这次输出以什么结尾，默认值 `"\n"`；改成 `""` 才能让多次 `print` 挤在同一行。
* 这里的循环变量 `i` 本身用不上，只是借序列把动作重复 m 次。

* **整块怎么打**
* 外层 `for j in range(n):` 控制行数，内层控制每行的星号个数。
* 内外层变量不能同名，撞名后内层会覆盖外层的值。
* 内层循环结束后、与外层循环体同级的位置写一句空 `print()`，利用它自带的换行给这一行收尾。
* 缩进决定一切：`print()` 缩进到内层里就变成每打一个星号换一行，与内层平级才是每打完一行换一次。
* > **易错点**：只把 `end` 改成空字符串而忘了行末换行，所有星号会全部挤在同一行。

```python
m = int(input("请输入长方形的长度："))
n = int(input("请输入长方形的宽度："))

for j in range(n):
for i in range(m):
print("*", end="")
print()
```

### 九九乘法表

* **先当表格看**
* 每个单元格里第一个数是列号（被乘数），第二个数是行号（乘数）；两者来历不同，混了就会写出错位的表。
* 九行九列共 81 个格子，实际只打印 45 个：右上角留空，第 3 行只有 3 格、第 4 行只有 4 格。
* 输出顺序是一行一行：先打完第一行再打第二行，屏幕光标本来也只能往下走。

* **循环分工**
* 外层 `for i in range(1, 10):` 管行，生成 1~9 共九行；`range(10)` 从 0 开始，不能直接用。
* 内层 `for j in range(1, i + 1):` 管列，列数跟着当前行号走：第 3 行只铺 3 格。
* 单元格写成 `f"{j}x{i}={j * i}"`，第一个数取内层 `j`、第二个数取外层 `i`。
* 内层用 `end="\t"` 以制表符隔开同一行的单元格；只写 `end=""` 时数字会挤成一坨。
* 内层跑完一轮后由空 `print()` 换行，再交给外层打印下一行。

```python
for i in range(1, 10):
for j in range(1, i + 1):
print(f"{j}x{i}={j * i}", end="\t")
print()
```

* **两处边界**
* 内层终点直接写 `i`，第一行 `range(1, 1)` 一个数都没有，整行会消失，必须写 `i + 1`。
* 内层也写 `range(1, 10)`，会打出九行九列的方阵，右上角本该空着的地方被填满。
