# 列表的方法：增删、排序与合并去重

## 方法就是对象自带的能耐

列表是什么、怎么定义、有什么特点，前面已经交代清楚了。这一节换个问法：一个列表能干什么。

先得把「方法」这个词说透，不然后面全是空中楼阁。方法是什么？就是日常生活里物品具备的能力，或者说物品的功能。

比如我们买了部手机，它能拍照、能打电话、能发短信——拍照、打电话、发短信，都是这部手机的功能。再比如买了台空调，它能制冷、能制热、还能通风，这些也都是空调的功能。物品，加上它身上那几样功能，这就是我们日常语境里的对应关系。

写 Python 的时候，这套对应关系换了个说法：功能叫**方法**，物品叫**对象**，而方法是归属于对象的。

> **定义**：方法是对象身上提供的功能，它不属于全局，只属于某一个对象。调用的时候必须先有那个对象，再点出它的方法。

那「对象」又是什么范围？在 Python、Java 这类语言里，有一句话：一切皆是对象。我们之前写程序时用过的布尔类型的值、字符串类型的值、数字类型（整数 `int`、浮点数 `float`）以及空值 `None`，统统都是对象。所以我们才会有「字符串对象」「布尔类型的对象」「数字类型的对象」这样的叫法——因为一切都是对象。

不同的对象有着不同的方法，不同的方法又实现不同的功能。这句话现在听着抽象，等讲到面向对象编程还会正式展开；眼下只需要有一个认知：方法是对象提供的功能，够了。

落到列表上就很具体了。「列表的常见方法」，指的就是列表这种数据类型内置的常见功能：往列表里添加元素、删除元素、对元素排序。这些功能都是列表类型自带的，不需要我们自己去实现，我们要学的只是怎么调、调哪一个。

## 六个常用方法

列表的方法不止六个，这里先把最常用的六个摆出来。它们的调用形式完全一致，都是「对象点方法名，后面跟参数」：

```python
s.append(10086)
```

这里的 `s` 是个变量名，它指向一个列表，所以 `s` 就是一个列表对象；通过这个列表对象，调用它内部的 `append` 方法，括号里指定要添加的元素。下面每一个方法都是这个形状，`s.` 开头，点出方法名。

| 方法 | 作用 | 要留意的点 |
| :--- | :--- | :--- |
| `append` | 在列表尾部追加元素 | 只往后加，不挑位置 |
| `insert` | 在指定索引之前插入元素 | 两个参数：插在哪个索引前、插什么 |
| `remove` | 移除列表中第一个匹配到的元素 | 按值删，不按位置删 |
| `pop` | 按索引删除元素 | 不写索引默认删最后一个，并返回被删的元素 |
| `sort` | 对列表元素排序 | 元素类型必须一致 |
| `reverse` | 反转列表元素 | 头变尾、尾变头 |

`insert` 的参数顺序值得单独说一句：第一个参数是索引，第二个参数是数据，中间用逗号分隔。`s.insert(0, 92)` 的意思是，在 0 号索引前面插入一个 92。

```text
插入前：  [56, 88, 90, 65]        索引：0   1   2   3
                     ↑ 在 2 号索引之前插一个 80
插入后：  [56, 88, 80, 90, 65]     索引：0   1   2   3   4
```

读图：80 顶在原来 2 号元素的位置上，原本的 2 号以及它后面的元素依次后移一位，索引整体加一。这就是「在指定索引之前插入」的实际效果——插入点上原来的元素并不会被覆盖，它只是往后挪了。

`remove` 是按值删的，而且只删第一个匹配到的。列表里如果本来就有两个 75，`s.remove(75)` 只会让从头匹配到的第一个 75 消失，第二个 75 原地不动。

`pop` 则是按位置删的，这两个别混。它还有一个附带的动作：删完之后会把那个元素返回回来，可以在前面拿一个变量接住，接到的就是被删掉的那个值。调用时不写索引，默认删最后一个。

`sort` 有个前提——列表里的元素必须是同一种数据类型。全是整数可以排，全是字符串也可以排；要是数字类型里混着布尔类型，那就没法准确地排序了。

`reverse` 是把列表翻个个儿。用图像处理来类比最直观：给一张图做一次水平翻转，原来的最右边跑到最左边。列表也一样，最后一个元素变成第一个，倒数第二个变成第二个，倒数第三个变成第三个，依此类推。调用就是 `s.reverse()`。

## 打上断点，一个方法一个方法看

方法的形式都是固定的，光看定义容易觉得「哦，懂了」，一动手就发现细节全是坑。所以我干脆把演示代码先准备好，在关键行上打个断点，用 debug 调试模式运行，一步一步往下走，看每个方法到底把列表改成了什么样。

先把准备动作交代清楚：定义一个名字叫 `s` 的列表，里面装九个整数，定义完先打印一次。

```python
s.append(188)      # 尾部追加
s.insert(2, 80)    # 在 2 号索引之前插入
s.remove(90)       # 删掉第一个匹配到的 90
s.pop(1)           # 按索引删，并把删掉的元素返回
s.pop()            # 不写索引，删最后一个
s.sort()           # 从小到大排序
s.reverse()        # 反转
```

`append(188)` 走一步，188 直接落在列表最末尾，接在 145 后面，位置不用你操心。

`insert(2, 80)` 走一步，80 落在 88 和 90 之间——它插在 2 号索引之前，自己占住了 2 号，原来的 2 号被挤到 3 号去。这一步最容易想岔的地方是以为 80 会顶掉原来的元素，实际上原元素只是挪了位置。

`remove(90)` 走一步，列表里本来有两个 90，被删掉的是第一个；再看一眼，另一个 90 还留在列表里。这就是「删除第一个匹配到的元素」的字面意思。

`pop(1)` 删的是 1 号索引上的元素，也就是刚才插进去的 80。删完它把 80 返回了出来，我在前面用一个变量接住，所以屏幕上能看到这个返回值就是 80。再调一次 `s.pop()`，后面没有参数，删的就是最后一个——188。

到这一步再整体打印一次，原来的 80 和末尾的 188 都不在了。

`sort()` 之前，列表是 56、88、65 这样乱着放的；调用之后重新打印，变成 56、65、72、88、90、100、145、209。`sort` 一被调用就地对元素排序，默认是从小到大。

`reverse()` 之后，209 变成第一个元素，145 第二个，100 第三个，90 第四个，头尾正好对调。

> **提示**：这六个方法名不用死记硬背。在 PyCharm 里敲出 `s.`，后面会自动弹出一串方法名；想追加元素就敲个 `a`，以 a 开头的都列出来，再敲 `app`，`append` 就出来了，鼠标双击补全，接着填参数即可。按需求挑方法，比背单词管用。

## 案例一：十个数字里挑出最小、最大和平均值

第一个案例的需求是这样：让用户输入十个数字，把这十个数字存进一个列表，然后对列表里的数字排序，排序之后输出其中的最小值、最大值和平均值。

拆开来想。用户要输入十次，也就是同一件事重复做十遍——重复执行就得用循环。那用 `while` 还是 `for`？这里循环次数是固定的十次，直接用 `for` 就行，不必让 `while` 再自己维护一个计数器。

整个案例可以拆成四步：定义列表、把用户输入的十个数字存入列表、排序、输出最小值最大值平均值。

```python
# 第一步：定义列表
number_list = []

# 第二步：用户输入的十个数字存入列表
for i in range(10):
    number = int(input("请输入一个有效的数字"))
    number_list.append(number)
print("数字列表", number_list)

# 第三步：对列表中的数字排序
number_list.sort()
print("排序后的数字列表", number_list)

# 第四步：输出最小值、最大值、平均值
print("最小值", number_list[0])
print("最大值", number_list[-1])
print("平均值", sum(number_list) / len(number_list))
```

第一步为什么要定义空列表？因为这个列表里的元素不是我们写死的，而是要用户一个一个录进来的，所以先准备一个空壳。定义一个空列表就是一对中括号，里面什么都不放：`number_list = []`。有元素的列表是一个中括号里写上元素，空列表只是括号里空着而已。

第二步，`for i in range(10)` 会生成一个十个元素的数字序列，循环体执行十次。循环体里先 `input` 拿用户输入，提示语是「请输入一个有效的数字」。这里有个必须处理的细节：`input` 拿到的永远是字符串，不能直接当数字用，所以套一层 `int()` 把它转成整数。拿到数字之后，调用 `number_list.append(number)` 把它追加进列表——往列表里加元素，调的就是 `append`。

十次循环走完，十个数字就都躺在 `number_list` 里了。这时候打印一次，标记成「数字列表」，方便后面对照。

第三步，排序同样要调列表的方法，`number_list.sort()`。这一行执行完，列表里的元素就按从小到大的顺序重新排好了。

第四步，取最小值最大值。既然第三步已经排好序，那第一个元素就是最小值，最后一个元素就是最大值，直接按下标取。最小值是 `number_list[0]`；最大值是 `number_list[-1]`——负索引表示从后往前数，`-1` 就是最后一个，不用去数「十个元素、索引到九」这件事，写 `-1` 既短又不会数错。

平均值要先把所有元素加起来，再除以元素的个数。累加求和当然可以自己写个循环遍历一遍，但 Python 直接给了现成的：`sum()` 求和，把列表传进去，它对里面所有元素做累加；`len()` 取长度，也就是元素个数，`len` 是 length 的简写。两者一除，平均值就出来了。

跑一遍：程序开始循环，连着提示十次输入，我随手输了 56、45、76、23、43 一路下去。输完之后先打印出这个装着十个数字的列表，再打印排好序的版本，元素齐刷刷从小到大；最小值、最大值跟着出来；最后平均值是 94.6。

> **提示**：`sum` 和 `len` 是 Python 的内置函数，不是列表的方法，所以写法是 `sum(number_list)` 而不是 `number_list.sum()`。除了这两个，Python 还提供 `min` 和 `max`，分别取最小值和最大值。这个案例里没用到它们——排完序按下标取已经够了——但知道有这么两个东西，以后能省几行。

> **易错点**：`input` 的结果不转 `int`，列表里装的就全是字符串，排序会按字符串的字典序排，`"109"` 会跑到 `"23"` 前面。平均值这里也要除以 `len(number_list)` 而不是把 10 写死，元素个数一变，写死的除数立刻失效。

这个案例把列表的定义和几个常用方法串起来用了一遍，值得自己动手默写一次。

## 案例二：合并两个列表，再去重

第二个案例换个方向：手上已经有两个列表 `number_list1` 和 `number_list2`，要把它们合并成一个列表，并对合并后的结果做去重——同一个值只留一个。

为什么要去重，看数字就明白：第一个列表里有两个 54，第二个列表里还有一个 54，合并之后列表里就躺着三个 54；123 也是，这边一个、那边一个。所谓去除重复元素，就是这些重复的值只保留一份，多出来的删掉。

所以这个案例就两步：第一步合并列表，第二步去除重复记录。第一步合并的花样比较多，先按最基础的一种写出来，再一步步简化。

### 笨办法：循环追加，再逐个判断去重

最直白的思路是：第二个列表里的元素，我一个一个取出来，追加到第一个列表的结尾。等第二个列表被搬空，第一个列表里的元素自然就是两个列表合并后的全部元素了。

```python
# 第一步：合并列表
for number in number_list2:
    number_list1.append(number)
print("合并后的原始列表", number_list1)

# 第二步：去除重复记录
new_list = []
for number in number_list1:
    if number not in new_list:
        new_list.append(number)
print("去除重复记录之后的列表", new_list)
```

第一段循环遍历的是 `number_list2`，注意是第二个列表，往第一个列表里塞。`for number in number_list2` 每转一圈拿出一个元素，交给 `number`，然后 `number_list1.append(number)` 把它追到第一个列表的尾部。

跑一下，两个列表的元素确实连成了一串：先是第一个列表原本的元素，接着是第二个列表的元素，一路拼在后面。第一步完成。

第二步去重。思路是再准备一个空列表 `new_list`，专门存放去重后的结果：把合并后列表里的元素一个一个取出来，取一个往 `new_list` 里放一个。

但这里有个陷阱——如果什么都不判断，直接 `new_list.append(number)`，那 `new_list` 里的元素会和原列表一模一样，一个不多一个不少，去重根本没发生。要真去重，就得在放之前先问一句：这个元素，`new_list` 里是不是已经有了？

已经有了就跳过，没有才放进去。这一问就得用 `if` 判断，而判断的依据是 `in` 运算符：

```python
number in new_list
```

`in` 用来判定一个元素是否存在于某个列表中，它的运算结果是一个布尔值：存在返回 `True`，不存在返回 `False`。

可我们要的条件恰好相反——不存在才添加。所以还得在 `in` 前面加一个 `not`，取反。逻辑运算符里我们学过三个：`and`（并且）、`or`（或者）、`not`（取反），这里用的就是 `not`。`number not in new_list` 读作「number 不在 new_list 里」，条件成立才执行 `append`。

这样一轮循环走完，`new_list` 里装的就是去重之后的结果了。再跑一遍看输出：合并后的原始列表里，54 出现三次（第一个列表里两个，第二个列表里一个），123 出现两次；而去重之后的 `new_list` 里，54 只剩一个，123 也只剩一个。

> **结论**：列表本身没有现成的「去重」方法，去重得自己造一个空列表，靠 `in` / `not in` 一边判断一边搬运。

这段代码短是短，可藏着个隐患：合并那一段虽然才两行，却是个循环。如果 `number_list2` 里有一万个元素，它就要转一万次，性能上是实打实的开销。所以合并这一步，值得换个写法。

### 星号解包：把列表摊开再装回去

换写法之前，先补一个概念——解包。

列表这类容器，本质上是一个整体，只不过这个整体里面装着一项一项的数据。所谓解包，就是把这个整体的外壳解开，让它散成一个一个独立的元素。反过来，把多个值合并塞进一个容器，叫组包。

用箱子打比方：解包是把箱子里的东西一件一件拿出来，组包是把一堆东西塞进同一个箱子。

有了这个概念，合并两个列表就变成一句话的事：把两个列表各自解开成独立的元素，再把这些元素一起装进一个新的列表。

```python
number_list = [*number_list1, *number_list2]
```

拆开看这一行。最外层的 `[]` 说明结果仍然是一个列表；里面的 `*` 就是解包操作符，`*number_list1` 表示把 `number_list1` 这个整体解开，元素一个个摊在这个位置上；中间的逗号是列表元素之间的分隔符，因为列表的多个元素之间就是逗号分隔的。

```text
number_list1 = [11, 22, 33]        number_list2 = [44, 55]
        |                                  |
   *number_list1                     *number_list2
        |                                  |
   11, 22, 33                          44, 55
        \                                /
         \                              /
      [ *number_list1 , *number_list2 ]
                      |
                      v
            [11, 22, 33, 44, 55]
```

读图：两个星号把两个列表的壳去掉，元素平铺到新列表的中括号里，新列表的第一部分来自 `number_list1`，第二部分来自 `number_list2`，一行完成合并，中间没有任何循环。

换成这种写法之后，下面打印和去重遍历的对象统统改成新的 `number_list`，去重那段代码原封不动。再运行，结果里 54 只剩一个，重复记录已经清掉，说明合并换了解包之后，整条链路照样成立。

### 加号：一行合并

还有更直接的一种：两个列表相加。

```python
number_list = number_list1 + number_list2
```

加号直接把两个列表接到一起，结果赋给新的 `number_list`。后面的打印和去重同样改成遍历 `number_list`，运行，合并成功，重复元素也被去掉了。

三种写法摆在一起，差别就清楚了。

## 三条合并路径怎么选

| 写法 | 代码 | 评价 |
| :--- | :--- | :--- |
| 循环追加 | `for number in number_list2: number_list1.append(number)` | 笨办法，不推荐；元素一多，循环次数就上去了 |
| 星号解包 | `number_list = [*number_list1, *number_list2]` | 借助解包特性，一行完成，思路清晰 |
| 加号 | `number_list = number_list1 + number_list2` | 最直接，日常首选 |

所谓「快速合并」，落在代码上就是后两种：加号最省事，解包则顺手把「容器可以被解开」这件事记住了。

最后回到 `in`。判断一个元素在不在列表里，写法就是把元素放在 `in` 左边，列表放在右边：

```python
100 in number_list
```

它的结果只会是 `True` 或 `False`：`True` 表示这个元素在列表里存在，`False` 表示不存在。前面加 `not` 就是取反——`100 not in number_list` 表示 100 不在列表里。案例里那句 `if number not in new_list` 的全部依据，就是这一条。
