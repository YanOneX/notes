## 本章检查点

合上笔记，能不看资料写出下面这段并说清每步结果，就算过关：

```python
nums = [3, 1, 4, 1, 5, 9, 2, 6]
nums = sorted(set(nums))          # 去重 + 排序
print(nums[:3], nums[-2:])        # 切片
count = {}
for n in nums:
    count[n] = count.get(n, 0) + 1
print(count)
```

说不清「`set` 之后为什么顺序变了」「`get` 的第二个参数干什么用」「`nums[-1]` 取的是哪个」，回头看 07 和 08。
