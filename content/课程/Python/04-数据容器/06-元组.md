# 元组

* **元组（tuple）**

* > **定义**：一种不可变的序列，类似列表，但一旦创建完成，里面的元素不允许修改，只能查询。

* 定义用一对小括号，元素之间逗号分隔：`t1 = (80, 95, 78, 50)`；`type` 为 `<class 'tuple'>`。

* 空元组写 `()` 或调 `tuple()`；只想要一个空的时候，直接写小括号更简洁。

* 存在的意义就是"这组数据只能查、不能改"：用列表存不该改动的一组数据，等于把门留在那里。

* **与列表的差别**

* 相同点：能存不同类型元素、元素可重复、元素有序。

* 不同点只有一条：元素可不可以修改。元组支持索引访问与切片，语法与列表完全一致。

* 方法只有两个：`count` 统计某元素出现次数，`index` 查找某元素首次出现的索引位置。

* `t1[0] = 100` 抛 `TypeError: 'tuple' object does not support item assignment`。

* > **注意**：`index` 查找的元素不存在时直接报错，不会返回 -1 之类的值。

* **单元素元组的逗号**

* `t3 = (100)` 得到的是 `int` 而不是元组：括号里只有一个元素时，解释器认为这是一对普通括号。

* 想要单元素元组，元素后面必须补一个逗号：`t3 = (100,)`。

* > **易错点**：决定它是不是元组的不是括号，而是逗号；那个逗号一省，类型就变了。

* **组包与解包**

* > **定义**：组包是把多个值合并进一个容器；解包是把容器拆成一个个独立的值，再分别赋给多个变量。

* 定义元组本身就是组包，括号可以省略：`t2 = 5, 7, 9, 1` 与 `t2 = (5, 7, 9, 1)` 等价，仍建议加括号让语义显式。

* 基础解包按位置一一对应：`a, b, c, d = t1`；变量个数必须与元素个数一致。

* 数量对不上直接报错：`ValueError: too many values to unpack (expected 5, got 6)`。

* 扩展解包用星号兜底：`first, second, *other, last = t1`；规则是星号最后处理，先给不带星号、位置最确定的变量分配，剩下的全归星号。

* 星号收集到的剩余元素会封装成列表而不是元组——列表可变，收集完还能继续处理。

* 星号也能往前挪：`*other, last2, last1 = t1`；读这种代码先找不带星号的变量，再让星号去兜底。

* **一行交换**

* `a, b = b, a` 一行完成两个变量的交换，不再需要临时变量。

* 这一行实际做了两步：右边 `b, a` 组包成元组，左边 `a, b` 按位置解包。

* 三变量轮换同理：`c, a, b = a, b, c`，右边组包成 `(100, 200, 300)`，左边按位置分发。

* **嵌套结构**

* 一张十人成绩单，外层元组十个元素（一行一个学生），每个元素再是一个五字段元组：学号、姓名、语文、数学、英语。

* 取数据靠下标：`s[0]` 学号、`s[1]` 姓名、`s[2]` 语文、`s[3]` 数学、`s[4]` 英语。

* 循环里解包可以替代下标：`for id, name, chinese, math, english in students:`，循环体全用变量名，可读性来自"第几个位置是什么"写进了变量名。

* 只取一两个字段时用下标更合适，全字段都要用时才值得解包。

* 输出对齐用转义字符 `\t`（制表符）撑开列宽，宽了减一个、窄了加一个；平均分只留一位小数用 `f"{avg:.1f}"`，`.1` 是一位小数，`f` 表示按浮点数处理。

* > **易错点**：平均分除的是科目数 3，不是 `len(students)`；`len(students)` 是学生人数 10，拿总分除以人数算出来的东西没有意义。
