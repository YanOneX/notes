# 列表

* **列表（list）**

* > **定义**：一次性存储多个数据的数据容器，每个数据都是它的一个元素。

* 定义语法是一次赋值，右侧是一对方括号，元素之间用逗号分隔：`s = [54, 45, 75, 108, 23, 78, 75]`。

* 空列表就是一对什么都不放的中括号：`number_list = []`；`type()` 查看类型得到 `<class 'list'>`。

* 只写出列表字面量而不赋值给变量，这个列表就没有名字也没有下文，编辑器会提示该语句似乎不起任何作用。

* **三条特点**

* 可以存储不同类型的元素；但工程实践中列表里基本只放同一类型的数据，"语法允许混放"与"通常不混放"是两件事。

* 有序：定义时是什么顺序，存储就是什么顺序，操作时也能按指定顺序进行。

* 可重复、可修改：相同值的元素允许共存，指定索引位置的元素可以重新赋值。

* **索引与越界**

* 元素有序，于是每个元素配一个索引（下标），正向从 0 起、反向从 -1 起。

* 同一个元素两种写法等价：七元素列表取第一个写 `s[0]` 或 `s[-7]`，取最后一个写 `s[6]` 或 `s[-1]`。

* 索引超出范围直接抛异常：`IndexError: list assignment index out of range`；正向上限是"长度减一"，反向下限是"负的长度"。

* **取值、改值与删值**

* 取值：`print(s[0])`、`print(s[-8])` 都打印列表头部的那个元素，负索引从尾部倒推。

* 改值：按索引定位后重新赋值，`s[5] = "ABC"` 只换掉第六个元素，其余元素一个不动。

* 删值用关键字 `del`，`del s[6]` 删掉第七个元素；位置本身不留空，后面的元素整体前移。

* > **提示**：`del` 是 delete 的缩写，删的是"这个位置上现在站着的元素"，列表长度随之减一。

* **有序性的验证**

* 用 `for item in s: print(item)` 逐个取出打印，输出顺序与存入顺序完全一致，这就是"有序"的实际含义。

* 位置固定是列表能按索引取值的底层原因：第几个就是第几个，因此 `for` 循环与列表是天然一对。
