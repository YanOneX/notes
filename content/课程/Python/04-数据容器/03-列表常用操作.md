# 列表常用操作

* **方法（method）**

* > **定义**：对象身上提供的功能，不属于全局，只属于某一个对象；调用时先有对象，再点出它的方法。

* 调用形式统一为"对象点方法名，括号里跟参数"，例如 `s.append(10086)`。

* Python 里一切皆是对象，布尔值、字符串、整数、浮点数、`None` 都是对象，不同对象有不同方法。

* **六个常用方法**

| 方法 | 作用 | 要留意的点 |
| :--- | :--- | :--- |
| `append` | 在列表尾部追加元素 | 只往后加，不挑位置 |
| `insert` | 在指定索引之前插入元素 | 两个参数：索引、数据 |
| `remove` | 移除第一个匹配到的元素 | 按值删，不按位置删 |
| `pop` | 按索引删除元素 | 不写索引默认删最后一个，并返回被删元素 |
| `sort` | 对列表元素排序 | 元素类型必须一致 |
| `reverse` | 反转列表元素 | 头变尾、尾变头 |

* `insert(2, 80)` 表示在 2 号索引之前插入 80：80 自己占住 2 号，原来的 2 号及其后元素依次后移一位。

* `remove(75)` 只删从头匹配到的第一个 75，后面重复的 75 原地不动；`pop(1)` 按索引删并把删掉的值返回。

* `sort()` 就地从小到大排序，前提是元素同一种数据类型；数字类型里混着布尔类型就无法准确排序。

* > **易错点**：`insert` 不会覆盖插入点上的元素，只是把它往后挤；用错成"顶掉"的预期，整个列表就错位了。

* **统计与合并**

* `sum()` 求和、`len()` 取元素个数、`min()` 取最小、`max()` 取最大，都是内置函数，写法是 `sum(number_list)` 而不是 `number_list.sum()`。

* 排序之后取最值可以直接按下标：最小值 `number_list[0]`，最大值 `number_list[-1]`。

* 合并两个列表有三条路径，差别在写法与开销上：

| 写法 | 代码 | 评价 |
| :--- | :--- | :--- |
| 循环追加 | `for number in number_list2: number_list1.append(number)` | 笨办法，元素一多循环次数就上去 |
| 星号解包 | `number_list = [*number_list1, *number_list2]` | 一行完成，顺带理解解包 |
| 加号 | `number_list = number_list1 + number_list2` | 最直接，日常首选 |

* **解包与组包**

* > **定义**：解包是把容器的外壳解开、散成一个个独立元素；组包是把多个值合并塞进同一个容器。

* `*number_list1` 里的星号就是解包操作符，元素被逐个摊在该位置上，外层 `[]` 保证结果仍是列表。

* **去重**

* 列表没有现成的去重方法，得自己造一个空列表，一边判断一边搬运。

* 判断依据是 `in` / `not in`：`number in new_list` 返回布尔值，`number not in new_list` 即取反。

* 去重循环：`if number not in new_list: new_list.append(number)`；漏掉这个 `if` 直接追加，去重根本不会发生。

* **列表推导式**

* > **定义**：按照一定的规则快速生成列表的语法。

* 格式一：`[要插入的值 for 变量 in 序列或列表]`，外层必须是中括号，`in` 后面可以接列表或 `range` 序列。

* 格式二：`[要插入的值 for 变量 in 序列 if 条件]`，`if` 挂在 `for` 后面，条件成立才插入，不成立直接跳过。

* `[i ** 2 for i in range(1, 21)]` 一行造出 1~20 的平方列表；`[i ** 2 for i in number_list if i % 2 == 0]` 只对偶数求平方。

* 只写 `[for i in range(1, 21)]` 会报错：说了从哪儿取数，却没说往列表里放什么。

* > **易错点**：`range(a, b)` 是左闭右开区间 $[a, b)$，"1 到 20"必须写 `range(1, 21)`，写 `range(1, 20)` 只到 19。

* > **易错点**：`input` 拿到的永远是字符串，不套 `int()` 就进列表，排序会按字典序进行，`"109"` 会排到 `"23"` 前面。
