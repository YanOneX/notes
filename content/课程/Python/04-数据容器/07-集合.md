# 集合

* **集合（set）**

* > **定义**：一种无序的、不可重复的、可修改的数据容器。

* 无序的直接后果是不支持索引访问，`s[0]` 这种写法在集合上用不了；也不要依赖打印出来的顺序。

* 不可重复是它存在的理由：列表和元组允许重复，同一个手机号放两次就存两份，数据就脏了；集合会自动去重，只留一份。

* 可修改指能往里加、也能从里面删；这一点与"定义好就动不了"的元组正好相反。

* 典型场景：存身份证号、手机号、银行卡号这类天然不该重复的数据。

* **定义与空集合**

* 用大括号定义，元素之间逗号分隔：`s1 = {5, 3209, 12, 5, 0, 0}`，重复的 5 和 0 会自动只留一个。

* 空集合只能用 `set()`；`{}` 定义出来的是字典，`type({})` 是 `<class 'dict'>`。

* 空集合打印出来是 `set()`，不是 `{}`。

* > **易错点**：`{}` 是空字典，不是空集合。两种容器都用大括号，来回切换时最容易踩这一脚。

* **增删方法**

| 方法 | 作用 |
| :--- | :--- |
| `add` | 往集合里添加一个元素 |
| `remove` | 删除指定元素，元素不存在会报错 |
| `pop` | 随机删除一个元素，并把删掉的元素返回 |
| `clear` | 清空集合 |

* `add` 加进去的元素会落在中间某个位置，不是接在末尾——集合根本没有"末尾"这个概念。

* `remove` 删的元素不存在时直接报错，不是静默跳过；`clear` 之后剩下的是 `set()`。

* **集合运算**

| 运算 | 方法 | 运算符 | 结果含义 |
| :--- | :--- | :--- | :--- |
| 交集 | `intersection` | `&` | 两个集合共有的元素 |
| 并集 | `union` | `\|` | 两个集合合起来、自动去重的元素 |
| 差集 | `difference` | `-` | 在前者中、但不在后者中的元素 |

* 方法与运算符完全等价，运算符短、读起来像数学式子；方法名把语义说得更明白，链式调用时更清楚。

* 差集有方向：`s2.difference(s3)` 与 `s3.difference(s2)` 结果不同，谁写在前面谁是被减的那一个；交集、并集不挑顺序。

* 交集可以连着写：`football_set & basketball_set & french_set & art_set`，中间结果仍是集合，能一路接到底。

* `union` 一次只合两个集合，四份名单要写成 `.union().union().union()` 的链式调用。

* "同时选修法语和艺术"是交集，"四门全选"是四个集合连续求交集，"选了足球但没选篮球"是差集。

* > **易错点**：差集换个顺序答案就换一批人。写之前先把"谁减谁"念一遍：`football_set - basketball_set` 问的是踢球但不打球的人。

* **推导式与频次统计**

* 集合推导式与列表推导式结构完全一样，唯一区别是最外层括号：`[]` 造列表，`{}` 造集合。

* `{s for s in football_set if s not in basketball_set}` 表示从足球名单里逐个取人，不在篮球名单里的收进新集合。

* 统计每人选了几门课要分两步：先用并集拿到去重后的全班名单，再把四份名单摊平成允许重复的列表。

* 摊平用解包：`all_list = [*football_set, *basketball_set, *french_set, *art_set]`。

* 计数用 `for s in all_set: print(f"{s}选修了{all_list.count(s)}门课程")`。

* > **提示**：集合会去重、记录不了"出现次数"，所以必须换到一个允许重复的容器里再用 `count` 数；集合负责去重拿名单，列表负责保留重复做计数。
