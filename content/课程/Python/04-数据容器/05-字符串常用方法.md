# 字符串常用方法

* **字符串（string）**

* > **定义**：装字符的数据容器，一个字母、一个数字、一个符号都算一个字符。

* 定义方式仍是双引号、单引号、三引号三种；`type` 为 `<class 'str'>`。

* 三个特点：不可变（定义好之后一个字符都改不了）、有序（每个字符位置固定）、可迭代（能用 for 逐个取出）。

* 不可变的代码表现：`s[4] = "X"` 抛 `TypeError: 'str' object does not support item assignment`。

* 字符取得到、改不动；`for ch in s: print(ch)` 会一个字符一行地全部输出。

* **查找与统计**

| 方法 | 作用 | 返回 |
| :--- | :--- | :--- |
| `find(sub)` | 从前往后找子串第一次出现的位置 | 索引；找不到返回 `-1` |
| `count(sub)` | 统计子串出现的次数 | 整数 |
| `startswith(sub)` / `endswith(sub)` | 判断是否以指定子串开头 / 结尾 | 布尔值 |

* `find` 找不到时返回 -1，不抛异常；`count` 统计的是全部出现次数，`"hello-Python-to-go".count("o")` 得到 4。

* **变换与切分**

| 方法 | 作用 | 返回 |
| :--- | :--- | :--- |
| `upper()` / `lower()` | 全部转大写 / 全部转小写 | 新字符串 |
| `split(sep)` | 按指定分隔符把字符串切成多段 | 列表 |
| `strip(chars)` | 去掉两端的空白字符或指定字符 | 新字符串 |
| `replace(old, new)` | 把旧的子串替换成新的 | 新字符串 |

* `split("-")` 返回 `['hello', 'Python', 'to', 'go']`；传 `" "` 是按空格切，那是一对引号中间夹一个空格，不是空字符串。

* `strip()` 不写参数默认去两端空格，`strip("*")` 则去两端的星号；`replace("-", "_")` 的两个参数是旧、新，别写反。

* 这些方法没有一个会改原字符串，全部算出一个新结果返回，原变量一个字符都不变——不可变性在这里兑现。

* > **结论**：字符串的方法是"只读"的，只给新结果、不动原件，要用结果就得拿新变量接住。

* **邮箱格式校验**

* 判定条件有两条：整串中 `@` 有且只有一个，点 `.` 至少有一个。

* 写法：`if mail.count("@") == 1 and mail.count(".") >= 1:`，两个条件用 `and` 连接。

* `@` 那条用 `== 1`，因为两个 `@` 同样非法；点那条用 `>= 1`，因为点的个数上不封顶。

* 另一种写法把点换成 `in`：`mail.count("@") == 1 and "." in mail`，只关心存在与否时 `in` 更贴切。

* > **易错点**：`in` 只回答"有没有"，不回答"有几个"，一个 `@` 和两个 `@` 在它眼里都是 `True`，所以 `@` 那一条必须用 `count`。

* 这种判断并不严谨，只是现有知识范围内的简化写法；真正校验邮箱格式要用正则表达式。
