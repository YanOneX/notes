# 模块与导入

* **模块（module）**
* > **定义**：一个以 `.py` 结尾的文件就是一个模块，模块是 Python 程序开发的基本组织单位。

* 模块里可以定义变量、函数、类，以及任何可执行的代码。
* 自己写的 `.py` 文件叫自定义模块；Python 官方随解释器提供的一批叫标准库，装好即可导入。
* 标准库常见项：`math` 数学运算、`random` 随机数、`os` 操作系统信息、`sys` 解释器与系统参数、`time` 与 `datetime` 时间日期、`csv` 读写 CSV 文件。
* 不导入就用不了：另一个文件里定义的函数，在当前文件直接调用会提示未解析的引用（unresolved reference），运行报 `NameError`。
* 三点好处：提高代码复用性、降低开发门槛、避免命名冲突——拆成模块后只需保证单个模块内部不重名。

* **导入整个模块**
* `import 模块名`，多个模块用逗号分隔：`import random, os`。
* 调用时必须带模块名前缀 `模块名.功能名`，因为功能名住在模块里，并没有进到当前文件。
* `import 模块名 as 别名`，之后只能写"别名点功能名"，原来的模块名不再认。
* `randint(start, end)` 生成一个整数随机数，两个端点都包含在区间内。

* **只导入需要的功能**
* `from 模块 import 功能`，`from` 后面写模块名、`import` 后面写功能名；调用时直接写功能名，不带前缀。
* 多个功能用逗号分隔：`from random import randint, choice`。
* 功能名也能起别名：`from random import randint as r_int`，之后只能用别名调用。
* `from random import *` 把模块内全部功能一次取进来，调用同样直接写功能名。

| 写法 | 导入的内容 | 调用方式 |
| :--- | :--- | :--- |
| `import random` | 整个模块 | `random.randint(1, 100)` |
| `import random as rd` | 整个模块，另起名字 | `rd.randint(1, 100)` |
| `from random import randint` | 一个功能 | `randint(1, 100)` |
| `from random import randint as r_int` | 一个功能，另起名字 | `r_int(1, 100)` |
| `from random import *` | 模块内全部功能 | `randint(1, 100)` |

* **书写位置**
* 约定把导入语句放在文件最上方，可执行代码放在它下面。
* 好处之一是依赖一目了然，扫一眼开头就知道这个文件用到了哪些模块。
* 好处之二是顺序天然正确，模块一定是先导入再使用，不会写着写着才发现某句话位置不对。
