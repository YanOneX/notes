## 本章检查点

合上笔记，能不看资料写出下面这段并说清结果，就算过关：

```python
def total(prices, discount=0.0, *extra):
    s = sum(prices) + sum(extra)
    return round(s * (1 - discount), 2)

def by_price(item):
    return item[1]

cart = {"apple": 3.5, "milk": 12.0, "egg": 8.8}
print(total(cart.values(), 0.1))
print(sorted(cart.items(), key=by_price))
print(sorted(cart, key=lambda k: -cart[k]))
```

说不清「`discount=0.0` 为什么必须写在 `*extra` 前面」「`by_price` 和 `lambda` 两种写法各自什么时候更好」「`return` 出去的是几个值」——回头看 03、05 和 01。
