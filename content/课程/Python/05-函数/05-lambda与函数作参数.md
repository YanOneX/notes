# lambda 与函数作参数

* **函数作为参数**
* 参数位置不仅能放数据，也能放函数对象本身：`calc(10, 20, add)` 把 `add` 递给形参 `oper`。
* 传的是函数对象，不是字符串：`add` 与 `"add"` 是两回事，后者只是几个字母。
* 函数体里 `oper(x, y)` 名字后跟一对小括号就是调用，`calc` 自己不关心做加法还是乘法。
* > **结论**：普通参数传的是数据，函数参数传的是逻辑。

* 第三个位置传数字会报 `TypeError: 'int' object is not callable`，因为 `oper(x, y)` 等于给数字加括号去调用。
* 本质上仍是函数的嵌套调用，只不过被调用的函数是外面递进来的。

* **lambda 表达式**
* > **定义**：`lambda 参数列表: 表达式`，是没有函数名的函数；`lambda` 是关键字，多个参数用逗号隔开，冒号后是函数体。

* 表达式的结果自动成为返回值，不需要也不能写 `return`，`lambda x, y: return x + y` 是语法错误。
* 冒号后面不能换行，函数体只能是单行的一个表达式；要写多步逻辑只能回到 `def`。
* 没有名字就无法直接调用，要先赋给变量：`outline = lambda: print("-" * 40)`，此时变量名起的作用和 `def` 的函数名一样。
* 只写 lambda 不赋值也不调用，编辑器会提示"语句似乎不起任何作用"——函数定义了却永远不会执行。

| 对比项 | 命名函数（def） | 匿名函数（lambda） |
| :--- | :--- | :--- |
| 函数名 | 必须有 | 没有，赋给变量后借变量名调用 |
| 定义方式 | `def 函数名(参数):` 加缩进函数体 | `lambda 参数: 表达式` |
| 函数体 | 可多行，可写复杂逻辑 | 只能一行表达式，不能换行 |
| 返回值 | 用 `return` 显式返回 | 表达式结果自动返回 |
| 典型用途 | 多处复用、逻辑复杂、需要文档说明 | 只在一处用一次、逻辑简单、作为参数传入 |

* 选择依据只有两条：函数复不复杂、要被用几次。一行表达式能写完且只在一处使用就用匿名函数，其余都建议用 `def`。

* **sort 的 key 参数**
* `list.sort(key=None, reverse=False)`，两个参数都有默认值，`key` 接收一个函数。
* `key` 指定的函数会作用到每个元素上算出一个值，排序按这个值进行；它不改变元素本身，也不负责比较大小，比较仍然由 `sort` 完成。
* `sort` 是原地排序，返回 `None`，不要用变量去接返回值，直接打印列表本身。
* `key=lambda item: len(item)` 按字符个数升序；长度相同的元素保持它们在原列表里的相对次序。
* `reverse=True` 逆序，默认 `False` 表示正序。

```python
data_list = ["C++", "Go", "Java", "JavaScript", "PHP", "Python", "Rust", "C"]
data_list.sort(key=lambda item: len(item))
print(data_list)  # ['C', 'Go', 'C++', 'PHP', 'Java', 'Rust', 'JavaScript']
```
