# 递归

* **递归调用**
* > **定义**：在函数内部调用函数自己，这种调用形式叫递归调用，简称递归。

* 阶乘的规律是 $n! = n \times (n-1)!$，一直套到 $1! = 1$ 为止。
* 没有终结点时程序会一路往下算 `1 * 阶乘(0)`、`0 * 阶乘(-1)`，永远没有尽头，撞上最大递归深度报 `RecursionError: maximum recursion depth exceeded`。
* 阶乘的终结点是 `n == 1` 时 `return 1`；先判断终结点，否则才走 `return n * 阶乘(n - 1)`。
* 每调用一层就往调用栈上压一层，压到终结点后从栈顶逐层弹出，每弹一层把当前的 n 乘上下一层带回的结果。

```python
def 阶乘(n):
if n == 1:
return 1
else:
return n * 阶乘(n - 1)
```

* **递与归**
* 递：层层递进，把原问题换成小一号的同类问题，参数每次减 1，直到终结点；少了这一步问题没有被拆小。
* 归：逐层回归，把终结点算出的确定结果一层层带回来；少了这一步结果带不回来。
* 十的阶乘依次是 $2!=2$、$3!=6$、$4!=24$、$5!=120$、$6!=720$、$7!=5040$、$8!=40320$、$9!=362880$、$10!=3628800$。
* 调试器里能看到调用栈叠十层，`n` 依次是 10 到 1；执行到 `return 1` 后逐层退回，最后打印 3628800。
* > **注意**：写递归的第一件事是把终结点想清楚；没有终结点一定撞 `RecursionError`，终结点写错结果同样是错的。
