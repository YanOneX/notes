# 函数的默认参数与不定长参数

我们先把位置参数、关键字参数这两套传法用顺了，再回头看参数列表本身——它还有两处绕不过去的麻烦。

一处是重复：某几个参数在绝大多数调用里都是同一个值。学生信息里的性别和城市，一个班里大多是男生、大多在北京，每次调用都把「男」「北京」再写一遍，纯属体力活。能不能在定义函数的时候就把它定成默认值，调用时想省就省？

另一处更棘手：要处理的参数个数根本说不准。今天传五个数，明天传十一个数，形参列表该写几个？写四个，传六个报错；写十个，传三个也报错。而这批数据究竟有几个，需求里压根没规定。

前者靠默认参数解决，后者靠不定长参数解决。两样东西的语法都只有一两个符号，但位置放错的代价很直接——要么编辑器当场画红线，要么值悄悄跑到别的参数身上去，运行完才发现结果不对。

## 默认参数：给参数一个「通常就是它」的值

默认参数还有个名字叫缺省参数。别被这个叫法唬住，缺省两个字不是术语黑话，就是字面意思：缺是缺少，省是省略——这个参数可以缺、可以省，前提是你给它设了默认值。

> **定义**：默认参数（缺省参数）是指在定义函数时直接为形参提供一个默认值；调用函数时，这个参数可以不传。

设置默认值的语法就一个等号，写在形参列表里：形参名 `=` 默认值。

```python
def get_stu(name, age, gender='男', city='北京'):
    return f'姓名：{name}，年龄：{age}，性别：{gender}，城市：{city}'
```

这里的 `gender='男'`、`city='北京'`，就是给这两个形参各设了一个默认值。一旦设了，调用这个函数时这两个参数就可以不指定；不指定，函数内部拿到的就是「男」和「北京」。

## 传了就用传的，不传才用默认值

同一个函数，三种调用方式，结果各不相同。

```python
print(get_stu('王林', 20))
print(get_stu('李慕婉', 18, '女'))
print(get_stu('韩立', 22, city='上海'))
```

```text
姓名：王林，年龄：20，性别：男，城市：北京
姓名：李慕婉，年龄：18，性别：女，城市：北京
姓名：韩立，年龄：22，性别：男，城市：上海
```

第一行只给了姓名和年龄，`gender`、`city` 一个都没指定，函数照样跑得通，输出里性别是男、城市是北京——这两个值就是定义时写下的默认值。

第二行传了三个位置参数，第三个「女」按顺序落到 `gender` 上，把默认的「男」盖掉了；`city` 还是没传，仍然用北京。

第三行是另一种情况：韩立是男生，性别想用默认值，可城市要改成上海。如果顺手写成 `get_stu('韩立', 22, '上海')`，位置参数一个接一个往下排，第三个位置是 `gender`，上海就会被当成性别，输出变成「性别：上海，城市：北京」——值没丢，只是装错了口袋。想让 `gender` 留着默认值、单独把 `city` 传进去，就得写成 `city='上海'` 这种关键字传参。

| 调用写法 | 落到 `gender` 的值 | 落到 `city` 的值 |
| :--- | :--- | :--- |
| `get_stu('王林', 20)` | 默认值 男 | 默认值 北京 |
| `get_stu('李慕婉', 18, '女')` | 传入 女，覆盖默认值 | 默认值 北京 |
| `get_stu('韩立', 22, city='上海')` | 默认值 男 | 传入 上海，覆盖默认值 |
| `get_stu('韩立', 22, '上海')` | 传入 上海，发生错位 | 默认值 北京 |

> **结论**：调用时给默认参数传了值，就以传进来的值为准，默认值被覆盖；没传，默认值才生效。

这一点和普通参数没有区别——默认参数并不是「特殊参数」，它只是在没收到值时有一个兜底的值而已。

## 默认参数必须排在普通参数后面

这条不是风格建议，是硬规定。

试着只给 `gender` 设默认值、`city` 还光着：`def get_stu(name, age, gender='男', city):`，编辑器立刻在 `city` 上画红线，函数根本定义不出来。把 `city='北京'` 补上，红线马上消失。

> **注意**：默认参数必须放在普通参数（没有设置默认值的参数）之后；一个函数里可以给多个参数设默认值，但它们都要集中排在非默认参数后面。

原因还是位置参数那套顺序对应的规则：调用时传进来的值只能从前往后填。默认参数要是排在前面、普通参数排在后面，那么某个位置上的值到底该跳过谁、落到谁头上就说不清了。与其运行时猜，不如在定义阶段直接禁止。

改回来就是前面那个写法：`def get_stu(name, age, gender='男', city='北京'):`。正确顺序永远是先写所有普通参数，再把所有默认参数一个一个排在后面，每个都写成 `参数名=参数值` 的形式。

## 参数个数说不准，固定形参就不够用了

来看一个需求：定义一个函数，根据传入的数据，计算这批数据当中的最小值、最大值和平均值。

乍一看不难。按函数定义的语法写一个 `calc_data`，括号里排四个形参，函数体里对这四个数求最小、最大、平均，收工。

可你把函数一写完，它就只能算四个数。调用时传四个，没问题；传六个、传八个九个，报错——形参只有四个，装不下；传三个也报错——形参要四个，不够。而需求说的是「这批数据」的最小值、最大值、平均值，这批数据到底有多少个，压根没限定。

这就是固定形参的死穴：定义了几个，调用时就必须传几个，不能多也不能少。

> **定义**：不定长参数也叫可变参数，指参数列表可以变化、不固定，主要用于函数定义及函数调用时参数个数不确定、不固定的场景。

不定长参数分两类：一类是基于位置参数传递的不定长参数，另一类是基于关键字参数传递的不定长参数。写法上的区别很直观——一个前面加一个星号，一个前面加两个星号。

## 一个星号：把位置参数收进元组

基于位置参数传递的不定长参数，声明方式是在形参名称前面加一个星号：

```python
def calc_data(*args):
    ...
```

星号加名字，整体才构成「不定长位置参数」的声明；`args` 只是接收这些数据的那个形参。

`args` 是 `arguments` 的缩写，就是参数的意思。这名字不是 Python 的关键字，纯粹是约定俗成的写法——你想写成 `*data`、`*a`、`*b`、`*c` 都行，只要前面那个星号在。不过实际写代码时建议就用 `*args`，别人一眼就知道这里收的是一串位置参数。

有了这个星号，调用时传几个都行：十个、二十个、三四个、四五个，全会被合并封装到 `args` 这一个形参里面。

一个形参怎么装得下这么多数据？因为这些数据最终被打包成了一个元组，`args` 的类型就是元组，元组本来就装得下任意多项数据。

> **注意**：`*args` 只接收基于位置传递的参数。调用时用 `key=value` 形式传进来的关键字参数，不会进到这个元组里。

既然 `args` 是元组，求这批数据的最小值、最大值、平均值就可以直接借用 Python 的内置函数了：

```python
def calc_data(*args):
    min_data = min(args)
    max_data = max(args)
    avg_data = sum(args) / len(args)
    return min_data, max_data, avg_data


print(calc_data(2, 7, 9, 10, 45))
```

```text
(2, 45, 14.6)
```

`min(args)` 取出元组里的最小值，`max(args)` 取出最大值；平均值不用现成的函数，用 `sum(args)` 把元素累加起来，再除以 `len(args)` 这个元素个数，就是平均数。

调试时把断点打在函数体第一行，能清楚看到 `args` 的值长这样：`(2, 7, 9, 10, 45)`。小括号括起来，五个数整整齐齐待在里面，确实是元组。

再往里塞十几个数也照样吃得下：

```python
print(calc_data(2, 7, 9, 10, 45, 73, 37, 93, 92, 111, 222))
```

最小值还是 2，最大值变成 222，平均值是 `63.72727272727273`。这一长串小数是因为除法除不尽。想让它短一点，用 `round` 保留指定位数就行：

```python
avg_data = round(sum(args) / len(args), 1)
```

第二个参数 `1` 表示保留一位小数，结果变成 `63.7`。

## 两个星号：把关键字参数收进字典

基于关键字传递的不定长参数，写法是在形参名称前面加两个星号：

```python
def calc_data(*args, **kwargs):
    ...
```

`KW` 是 `keyword`（关键字）的缩写，所以这个形参约定俗成叫 `kwargs`。同样地，名字可以换，写成 `**options`、`**data` 都合法，本质是前面那两个星号。

以关键字方式传进来的多个键值对，会被 `kwargs` 接收并封装成一个字典。字典本来就是存键值对的，而关键字参数 `key=value` 正好一对一对：`round=3` 里 `round` 是键、`3` 是值，`print=True` 里 `print` 是键、`True` 是值。

验证起来很直接：在函数体里先打印一下 `kwargs`，调用时传 `round=3`、`print=True`，输出就是 `{'round': 3, 'print': True}`；换一次调用，一个关键字参数都不传，输出就是一个空字典 `{}`。

```text
calc_data(2, 7, 9, 10, 45, round=3, print=True)
   │
   ├─ 位置参数 ──▶ args   = (2, 7, 9, 10, 45)            元组
   │
   └─ 关键字参数 ─▶ kwargs = {'round': 3, 'print': True}   字典
```

一次调用里的参数会按传法分流：位置参数全进 `args` 元组，关键字参数全进 `kwargs` 字典，两条路互不干扰。

## 用选项控制函数的行为

前面的 `calc_data` 有个别扭的地方：保留一位小数是写死在 `round(..., 1)` 里的。将来如果某次想保留三位，就得改函数源码——这显然不合理。

合理的做法是把「保留几位」变成一个参数传进来：传 `round=1` 就保留一位，传 `round=3` 就保留三位。顺带还能再加一个开关 `print=True`，表示算完顺手把结果打印出来；不传或者传 `False` 就不要打印。

这两个参数都是可传可不传的选项，正好交给 `**kwargs` 收。

```python
def calc_data(*args, **kwargs):
    """
    根据传入的一批数据，计算最小值、最大值及平均值
    :param args: 不定长位置参数，需要计算的这批数据
    :param kwargs: 不定长关键字参数，round 保留的小数位个数，print 是否打印输出
    :return: 最小值、最大值、平均值
    """
    min_data = min(args)
    max_data = max(args)
    avg_data = sum(args) / len(args)

    if kwargs.get('round') is not None:
        avg_data = round(avg_data, kwargs.get('round'))

    if kwargs.get('print'):
        print(f'最小值：{min_data}，最大值：{max_data}，平均值：{avg_data}')

    return min_data, max_data, avg_data
```

函数头 `def calc_data(*args, **kwargs)` 把两种不定长参数并列写在了一起：前面收数据，后面收选项。函数上方那段三引号是文档注释，把 `args`、`kwargs` 里能放什么、返回什么交代清楚——`kwargs` 可能收到 `round`（保留的小数位个数）和 `print`（是否打印输出），返回值是最小值、最大值、平均值这三项。

函数体分三段看：

- 求最小值、最大值、平均值这三行原封不动，和数据打交道的逻辑跟只有一个星号时完全一样；
- `kwargs.get('round')` 从字典里按键取值。这个键没传时，`get` 返回 `None`；所以用 `is not None` 判断——只要值存在，就拿它当位数对平均值做四舍五入，不存在就保持原始计算结果；
- `print` 这个键不用判断 `None`，因为它的值本身就是布尔类型，`if kwargs.get('print'):` 直接判真假就够了，为 `True` 才进分支打印。

## 把选项传进去看效果

五个数，加上 `round=3` 和 `print=True`：

```python
calc_data(2, 7, 9, 10, 45, round=3, print=True)
```

```text
最小值：2，最大值：45，平均值：14.6
```

打印出来了，但小数位只有一位，说好的三位呢？这不是 `round` 失灵。这五个数加起来是 73，73 除以 5 正好等于 14.6，能除得尽，`14.6` 是准确结果，不是四舍五入出来的。`round` 只在除不尽、或者小数位超过指定位数时才起作用。

换成十一个数，一个关键字参数都不传：

```python
print(calc_data(2, 7, 9, 10, 45, 73, 37, 93, 92, 111, 222))
```

```text
(2, 222, 63.72727272727273)
```

这次 `kwargs` 是空字典，两个 `if` 都不成立：不打印，也不保留位数，函数直接把三个结果返回，`print` 把整个元组显示出来，平均值就是那一长串除不尽的小数。

在后面补一个 `round=2`，同一个调用立刻变成 `63.73`；`round=3` 是 `63.727`；`round=4` 是 `63.7273`。再加上 `print=True`，结果会先在函数内部打印一遍。

## 数据和选项：两种不定长参数的分工

两类不定长参数，写法只差一个星号，真正的区别在用途上。

不定长位置参数处理的是数量不确定的**数据**，关注点在于这些数据本身；不定长关键字参数处理的是数量不确定的**选项**，作用在于控制函数的行为。

> **提示**：什么叫数据、什么叫选项？到奶茶店点一杯珍珠奶茶，这杯珍珠奶茶就是核心数据。而甜度要少糖、冰度要去冰、加料加布丁加珍珠、杯型要中杯还是大杯——后面这一串全是选项，选项是为那杯奶茶服务的。

`calc_data` 里也是同样的分工：`*args` 收的那一串数字是要计算的数据，`**kwargs` 里的 `round`、`print` 是决定怎么算、要不要打印的选项。

| 写法 | 接收的传参方式 | 封装成的类型 | 主要用途 |
| :--- | :--- | :--- | :--- |
| `*args` | 位置参数 | 元组 | 数量不确定的数据 |
| `**kwargs` | 关键字参数 | 字典 | 数量不确定的选项 |

这两类同时出现在一个函数里时，还有一条顺序规矩：先定义不定长位置参数，再写不定长关键字参数。

道理和位置参数必须排在关键字参数前面是一样的——位置参数靠位置一一对应，天然要站在前面；关键字参数靠名字对号入座，站在后面才不会把顺序搅乱。`def calc_data(*args, **kwargs)` 这个函数头，就是这条规矩的标准形态。

顺序记牢两句话：默认参数永远站在普通参数后面；两类不定长参数同时出现时，位置的永远站在关键字的前面。位置在前、关键字在后，这条线从形参列表一直贯到函数调用，两头都不能颠倒。
