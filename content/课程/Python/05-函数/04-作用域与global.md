# 作用域与 global

* **全局变量与局部变量**
* > **定义**：在函数外部定义的变量叫全局变量；在函数内部定义的变量叫局部变量，形参本质上也是局部变量。

* 全局变量一般写在文件顶部，整个文件任何位置都能访问：函数外面能读，函数内部也能读。
* 局部变量只在函数内部有效，函数执行完毕就被自动销毁。
* 在函数外访问局部变量报 `NameError: name 'pi' is not defined`，而且报错那一行之后的代码全部不再执行。
* > **易错点**：`NameError` 是"这个名字根本不存在"，不是"值取不到"——函数一结束，局部变量连同名字一起消失了。

* **同名不同身**
* 在函数内部给变量赋值，等于新建一个局部变量，而不是修改同名的全局变量。
* 函数内部对全局变量只有"读"的资格，没有"写"的资格：函数里打印 10000，函数外仍是 100。
* 这一条同时解释了两个现象：函数里读全局变量没问题，函数里写同名变量外面不变。

* **global 声明**
* `global 变量名` 单独一行，写在任何针对该变量的赋值之前；顺序反了在编译阶段就报语法错误。
* 加上之后，函数内对该名字的赋值直接落到全局变量上，函数内外打印都是新值。
* 项目里基本不用：调用一次改一次，代码一长就没人知道某一刻这个变量到底是几，调试和维护都变难。
* 更推荐的做法是数据用参数传进去、结果用返回值带出来，输入输出全写在签名和 `return` 上。
* 适用场景是"全局只有一份、要跨多次调用持续存在"的状态：调试开关（`enable_debug` / `disable_debug`）、记录函数被调用次数的计数器。
