# 默认与不定长参数

* **默认参数（缺省参数）**
* > **定义**：定义函数时直接为形参提供一个默认值，调用时这个参数可以不传。

* 语法就是在形参列表里写 `形参名=默认值`，如 `def get_stu(name, age, gender='男', city='北京'):`。
* 传了值就以传入值为准，默认值被覆盖；没传才用默认值。默认参数并不特殊，只是没收到值时有个兜底。
* 必须排在所有普通参数之后；多个默认参数集中排在非默认参数后面，否则函数根本定义不出来。
* 想保留前面的默认值、只改后面的参数，必须用关键字传：`get_stu('韩立', 22, city='上海')`。
* > **易错点**：`get_stu('韩立', 22, '上海')` 里"上海"按位置落到 `gender` 上，输出变成"性别：上海，城市：北京"——值没丢，装错了口袋。

* **不定长位置参数（`*args`）**
* > **定义**：在形参名前面加一个星号，把任意多个位置实参收进一个元组。

* `args` 是 arguments 的缩写，不是关键字；写成 `*data` 也合法，约定俗成用 `*args`。
* 只收位置实参；用 `key=value` 形式传进来的关键字实参不会进这个元组。
* 收到的是元组，可以直接交给 `min`、`max`、`sum`、`len`：最小值 `min(args)`、最大值 `max(args)`、平均值 `sum(args) / len(args)`。
* 固定形参的死穴是定义几个就必须传几个，多一个少一个都报错；个数不确定时用它。

* **不定长关键字参数（`**kwargs`）**
* > **定义**：在形参名前面加两个星号，把任意多个关键字实参封装成一个字典。

* `kwargs` 取自 keyword；一个关键字参数都不传时，它就是空字典 `{}`。
* 适合收"选项"：`round` 控制保留几位小数，`print` 控制算完是否打印。
* 取键用 `kwargs.get('round')`，缺键返回 `None`，所以用 `is not None` 判断；布尔型选项直接 `if kwargs.get('print'):` 判真假。

* **两类不定长参数的分工**

| 写法 | 接收的传参方式 | 封装成的类型 | 主要用途 |
| :--- | :--- | :--- | :--- |
| `*args` | 位置参数 | 元组 | 数量不确定的数据 |
| `**kwargs` | 关键字参数 | 字典 | 数量不确定的选项 |

* 位置不定长收"数据"，关键字不定长收"选项"：数据是要处理的对象，选项决定怎么处理、要不要打印。
* 同时出现时先写位置、再写关键字：`def calc_data(*args, **kwargs)`；顺序反了与"位置参数必须在关键字参数前"是同一条道理。
* 两条顺序线：默认参数永远站在普通参数后面；两类不定长参数同时出现时，位置的永远站在关键字前面。
* 形参表里一旦出现 `*args`，它后面的形参就只能靠关键字接值——位置实参来多少它收多少，会把后面的值一并吞进 `args`。

```python
def calc_data(*args, **kwargs):
min_data = min(args)
max_data = max(args)
avg_data = sum(args) / len(args)

if kwargs.get('round') is not None:
avg_data = round(avg_data, kwargs.get('round'))

if kwargs.get('print'):
print(f'最小值：{min_data}，最大值：{max_data}，平均值：{avg_data}')

return min_data, max_data, avg_data
```

* **综合用例：订单结算**
* 商品件数不确定，每件记成"名称、价格、数量"，用 `*args` 收；优惠券、积分、运费各一个，用关键字参数收。
* 公式：订单总金额 = 商品总金额 − 优惠券 − 积分抵扣 + 运费；运费是成本，最后一个符号是加号。
* 商品总金额用列表推导式逐件相乘再 `sum()`：`[goods[1] * goods[2] for goods in args]`，下标 0 是名称、1 是价格、2 是数量。
* 优惠券两个条件缺一不可：`total_cost >= 5000 and coupon <= total_cost`，只判满 5000 会让一张万元券把订单扣成负数。
* 积分抵扣先用整除换成钱再比：`score // 100`，判断条件与扣减金额两处都要写；用 `/` 会冒出角分，违背"只能整百抵扣"。
* 三个优惠参数配默认值 `coupon=0, score=0, express=0.0`，只传商品也能跑；`express=9.9` 传给默认值 `0` 会标黄，属于 int 与 float 的类型不一致提示，不影响运行。
