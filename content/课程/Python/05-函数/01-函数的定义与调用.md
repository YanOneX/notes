# 函数的定义与调用

* **函数定义**
* 结构固定为 `def` + 函数名 + 一对括号 + 冒号 + 缩进函数体；括号里写形参，多个形参用逗号分隔。
* `def` 只把函数定义出来，定义本身不执行；函数体要等被调用的那一刻才开始跑。
* 形参要几个、要不要返回值，由业务需求决定：结果依赖什么就从外面拿什么，要交回结果就写 `return`。
* 命名用下划线分隔多个单词，做到见名知意（`rectangle_area`、`triangle_area`），不用 `a1`、`b2` 这类缩写。

* **return 的两条硬规矩**
* > **定义**：`return` 把函数算出的结果交回调用处，并立即结束当前函数的执行。

* 必须写在函数体最后一行：执行到它就结束，后面的语句永不执行，写在中间等于制造死代码。
* 只负责交结果，没有打印功能；要在控制台看到结果，先用变量接住返回值，再 `print` 这个变量。
* 调用表达式本身就是一个值，可以直接放进 `print`、赋给变量或继续参与运算——前提是函数有返回值。

* **多返回值与解包**
* `return a, b` 用逗号分隔多个结果，Python 自动把它们打包成一个元组，`type()` 输出 `<class 'tuple'>`。
* > **结论**：所谓"返回多个值"，实际返回的是一个元组。

* 解包按位置一一对应：`area, length = circle_area_length(10)`，左边变量个数必须与元素个数相等，多一个少一个都不成立。
* `round(number, n)` 四舍五入并保留 n 位小数，是内置函数，不需要 import。

```python
def circle_area_length(r):
return round(3.14 * r * r, 1), round(2 * 3.14 * r, 1)


area, length = circle_area_length(10)
print(area, length)   # 314.0 62.8
```

* **说明文档（docstring）**
* 三引号字符串写在函数体第一行，身份就是函数的说明文档；第一行一句话说清这个函数干什么。
* 每个形参一条 `:param 参数名:`，有几个形参写几条；有 `return` 才写 `:return:`，多个返回值按返回顺序列全。
* 查看方式有三种：翻到定义处读、`help(函数名)`、IDE 里鼠标悬停函数名。
* `help` 后面不加括号——`help(rectangle_area)` 是把函数对象交给 `help`，`rectangle_area()` 是调用它。
* Python 没有独立的多行注释语法，三引号本质是字符串；单独成句、不赋给任何变量时被当作注释使用。

* **嵌套调用与调用栈**
* > **定义**：函数调用遵循栈（stack）结构，只允许在栈顶一端入栈和出栈，特点是 LIFO（后进先出）。

* 程序运行时永远执行栈顶那一段代码；A 调 B、B 调 C 时 C 在最上面，最先结束、最先出栈。
* 调用顺序是 A→B→C，执行完毕的顺序是 C→B→A；每个函数的后半段要等它调用的函数出栈后才轮得到。
* 调试时 F7 单步进入会钻进函数内部，F8 单步跳过不进入被调函数；断点配合"线程和变量"面板能看到整个调用栈，最上面一行就是栈顶。
* > **易错点**：把调用顺序当成执行顺序。想不清就把栈画出来，谁在栈顶谁在跑。
