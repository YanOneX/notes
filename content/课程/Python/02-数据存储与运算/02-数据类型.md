# 数据类型

### 五种基础类型

* **基础数据类型（basic data types）**

    * > **定义**：Python 中最常用的一组内置数据类型，共五种。

    | 类型 | 名称 | 说明 | 例子 |
    | :--- | :--- | :--- | :--- |
    | `int` | 整数 | 正整数、负整数、零 | `10`、`-100`、`0` |
    | `float` | 浮点数 | 带小数点的小数，不分正负 | `8.5`、`3.14`、`-3.5` |
    | `str` | 字符串 | 描述文本，必须用引号引起来 | `"hello"`、`'Python'` |
    | `bool` | 布尔 | 真或假，只有两个值 | `True`、`False` |
    | `NoneType` | 空值 | 只有一个值，表示没有值 | `None` |

    * 辨认方式：看到 `3.14` 想到 `float`，看到引号包着的想到 `str`，看到 `True`、`False` 想到 `bool`，看到 `None` 想到 `NoneType`。

    * 空值类型的含义是这个位置为空、或者说没有值。

* **值的类型（type of value）**

    * > **定义**：变量本身没有类型，变量里存的那个数据才有类型。

    * 变量是容器，容器本身不分类；往容器里放什么，容器里的东西才分类型。

    * `type(number)` 盯着的是容器里那个值，变量名只是一个门牌号。

### 类型查看与判断

* **type()**

    * > **定义**：内置工具，返回括号内数据的类型，写法为 `type(要查的数据)`。

    * `type("hello")` 得 `<class 'str'>`，`type(10)` 得 `<class 'int'>`，`type(3.14)` 得 `<class 'float'>`，`type(None)` 得 `<class 'NoneType'>`。

    * `class` 在这里就是"类型"的意思，`str` 是 string 的缩写。

    * `type` 只负责查，不负责显示；要看到结果必须再包一层 `print`。

    * > **易错点**：`type(变量)` 打印的是值所属的类型，不是"变量被声明成的类型"——Python 定义变量时根本没有声明类型这一步。

* **isinstance()**

    * > **定义**：判断某个数据是否属于指定类型，返回布尔值，写法为 `isinstance(数据, 类型)`。

    * `isinstance(-100, int)` 得 `True`，`isinstance(-100, float)` 得 `False`，`isinstance(-100, bool)` 得 `False`。

    * 想"看一眼是什么"用 `type`，想"验证是不是"用 `isinstance`；两者都能用在字面量和变量上。

### 类型转换

* **类型转换（type conversion）**

    * > **定义**：用内置函数把数据从一种类型转成另一种类型。

    | 工具 | 作用 |
    | :--- | :--- |
    | `int()` | 转成整数类型 |
    | `float()` | 转成浮点数类型 |
    | `str()` | 转成字符串类型 |
    | `bool()` | 转成布尔类型 |

    * `str(18)` 把整数变成 `"18"`：数值没变，类型变了，转换之后才有资格参与字符串拼接。

    * `bool()` 目前没有使用场景，知道有这么一个工具即可。

* **数值解析（numeric parsing）**

    * > **定义**：`int()` 按整数写法解析，`float()` 按小数写法解析，两者接受的输入范围不同。

    * `int("1000")` 得 1000；`int("10.5")` 直接报错，因为 `10.5` 不是合法的整数字面量。

    * 要处理小数就换 `float()`：`float("10.5")` 得 10.5。

    * > **易错点**：题目只说"两个数"而没有限定整数时，用 `int()` 会挡住小数输入，应改用 `float()`。
