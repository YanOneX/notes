# 从变量到字符串：Python 的基础数据类型

字面量认过了，变量也定义过好几个了，可你有没有回头想过一个问题：写 `a = 10` 的时候，我们从头到尾没告诉 Python 这个 `a` 是什么类型，它怎么就那么自然地跑起来了？这一篇就把这件事说清楚——常见的基础数据类型有哪几种，怎么查、怎么判断，以及其中最麻烦也最常用的字符串，到底该怎么写、怎么拼。

## 五种基础数据类型

Python 的数据类型挺多，这里先看最基础的五个。其实这五个我们早就见过——讲字面量的时候一个一个都写过，只是当时没给它们安名字。

第一类，`int`，整数。正数、负数、零，只要是整数，统统用 `int` 表示。`10` 是 `int`，`-100` 是 `int`，`0` 也是 `int`。

第二类，`float`，浮点数，也就是小数。`8.5`、`3.14`、`-3.5`，不分正负，只要带小数点就是 `float`。

第三类，`str`，字符串，用来描述文本。这里有一条从第一行代码起就立下的规矩：字符串必须用引号引起来。前面我们一直用双引号，其实单引号也行——字符串的表现形式有好几种，下一节专门拆开讲。

第四类，`bool`，布尔类型，表示真或假，里面只有两个值：`True` 和 `False`。

第五类，`NoneType`，描述空值。这个类型比较特殊，它里面只有一个值 `None`，含义是这个位置为空、或者说没有值。

| 类型 | 名称 | 说明 | 例子 |
| :--- | :--- | :--- | :--- |
| `int` | 整数 | 正整数、负整数、零，只要是整数都算 | `10`、`-100`、`0` |
| `float` | 浮点数 | 带小数点的小数，不分正负 | `8.5`、`3.14`、`-3.5` |
| `str` | 字符串 | 描述文本，必须用引号引起来 | `"hello"`、`'Python'` |
| `bool` | 布尔 | 真或假，只有两个值 | `True`、`False` |
| `NoneType` | 空值 | 只有一个值，表示没有值 | `None` |

这五类先记住长相：看到 `3.14` 想到 `float`，看到引号包着的想到 `str`，看到 `True`、`False` 想到 `bool`，看到 `None` 想到 `NoneType`。至于更高级的数据类型，后面还有专门的章节。

## 变量没有类型，值才有类型

现在回到开头那个问题。定义 `a = 10`，`a` 是变量名；定义 `name = "Python"`，`name` 也是变量名。这两行里，我们谁都没有指定类型。那么问题来了：没指定，这个变量到底有没有类型？

有。但这句话得说得再准确一点——**变量本身没有类型，变量里存的那个数据才有类型**。

变量是什么？是一个存储数据的容器。容器本身没有类型，往容器里放什么，容器里装的东西才有类型。所以查变量类型时，查的其实是这个容器里那份数据的类型。

想把类型看个究竟，Python 内置了一个工具：`type`。它的写法是 `type(括号里放要查的数据)`。

```python
print(type("hello"))
print(type(10))
print(type(3.14))
print(type(True))
print(type(False))
print(type(None))
```

运行结果：

```text
<class 'str'>
<class 'int'>
<class 'float'>
<class 'bool'>
<class 'bool'>
<class 'NoneType'>
```

`class` 在这里就是"类型"的意思，后面跟的 `str` 是 string 的缩写，所以 `<class 'str'>` 读作"这是字符串类型"。

有个细节容易看混：`print("hello")` 输出的是字符串本身，`print(type("hello"))` 输出的才是它的类型。想让 `type` 的结果露出来，就必须再用 `print` 包一层——`type` 只负责查，不负责显示。

`type` 里也可以传变量：

```python
number = -100
print(type(number))
```

结果还是 `<class 'int'>`。注意这里查的不是"`number` 这个容器是什么类型"，而是"`number` 里装的 `-100` 是什么类型"。

```text
   number  --->  [  -100  ]  --->  type = int
   （变量名）     （容器里的值）      （值才有类型）
```

一句话概括这张图：`type(number)` 的眼睛盯着的是右边那个值，变量名只是个门牌号。

> **易错点**：`type(变量)` 打印出来的是值所属的类型，不是"变量被声明成的类型"。Python 定义变量时根本没有声明类型这一步，你写什么进去，它就是什么类型。

## 用 isinstance 判断"是不是"

`type` 回答的是"你是什么"，还有一个工具回答的是"你是不是"——`isinstance`。

```python
isinstance(数据, 类型)
```

它要两项参数：第一项是待判定的数据，第二项是拿来比对的类型。执行完返回一个布尔值：是，返回 `True`；不是，返回 `False`。

```python
number = -100
print(isinstance(number, int))
print(isinstance(number, float))
print(isinstance(number, bool))
```

结果：

```text
True
False
False
```

三句话分别是：`number` 是不是 `int`？是；是不是 `float`？不是；是不是 `bool`？不是。所以输出 `True False False`。

敲这段代码有个小门槛。输入 `is` 之后别急着回车，PyCharm 的提示列表里以 `is` 开头的候选不止一个，看清楚再选，或者干脆双击补全。

两个工具的区别，一张表说清：

| 工具 | 作用 | 返回什么 |
| :--- | :--- | :--- |
| `type(x)` | 查看 x 的类型 | 类型本身，如 `<class 'int'>` |
| `isinstance(x, T)` | 判断 x 是否属于类型 T | 布尔值 `True` / `False` |

两者都能用在字面量上，也都能用在变量上。想"看一眼是什么"用 `type`，想"验证是不是"用 `isinstance`。

## 字符串的三种定义方式

从写第一个 `hello world` 起，字符串就一直是双引号包着的。其实 Python 里字符串有三种写法：双引号、单引号、三引号。前两种完全等价，只是写法不同；第三种是另一回事。

### 双引号与单引号

```python
s1 = "hello"     # 双引号定义
s2 = 'Python'    # 单引号定义
```

敲法上有个小差别：双引号要按住 Shift 再加引号键，单引号直接按引号键就行，不用按 Shift。初学的时候有人在键盘上找半天单引号，其实就是那一个键。

限制也很明确：用单引号或双引号定义的字符串，**不能直接换行**。你要是硬在引号中间敲一个回车，PyCharm 会很"智能"地把它拆成两个字符串，再自动拼回去——看着像是换行了，实际上代码已经被改成了两个字符串相加。真要跨行，得做字符串拼接，那是后面的事。所以记住：单引号字符串和双引号字符串，一行就是一行。

### 三引号与多行字符串

第三种写法是三个引号开头、三个引号结尾，中间放内容：

```python
s3 = """
hello
    欢迎大家进入到 Python 课程的学习
    大家记得一键三连哟
"""
```

三个单引号或三个双引号都可以，官方推荐用三个双引号。

三引号与前两种最大的不同是：**它支持换行，而且原样输出**。你写的时候长什么样，打印出来就长什么样——换行保留，Tab 键按出来的缩进也保留。上面这段在开头的引号之后先换了一行，所以打印出来的第一行是空的；`hello` 顶格；后两行带着缩进。

把 `s1`、`s2`、`s3` 依次打印，输出是这样的：

```text

hello
    欢迎大家进入到 Python 课程的学习
    大家记得一键三连哟
```

> **易错点**：注释的位置。三引号字符串里，如果把 `# 这是注释` 写进引号内部，它就不再是注释了，而是字符串内容的一部分，会跟着原样打印出来。注释必须写在字符串结束之后、这一行代码的末尾，或者单独一行放在字符串外面。

三个变量用 `type` 一查，都是 `<class 'str'>`——写法不同，类型相同。

| 定义方式 | 写法 | 能否换行 | 常用场景 |
| :--- | :--- | :--- | :--- |
| 双引号 | `"内容"` | 不能 | 日常最常用 |
| 单引号 | `'内容'` | 不能 | 与双引号等价，看项目习惯 |
| 三引号 | `"""内容"""` | 能，且原样保留格式 | 多行文本 |

既然单引号和双引号定义出来的字符串一模一样，项目里到底用哪个？原则只有一条：**同一个项目里，要么统一用双引号，要么统一用单引号**，别这一段双引号、下一段单引号地混着写。三引号则留给多行字符串；它后面还有一个用途是写文档注释，到时候再展开。

## 字符：组成字符串的基本单位

字符串里的每一个字母、每一个汉字、每一个符号、每一个数字，都是一个字符。

字符是文本世界里的基本单位，也是组成字符串的基本单位。为什么叫"字符串"？就是把多个字符"串"在一起。`"hello"` 是五个字符串起来的，`"你好"` 是两个字符串起来的，`"a1，"` 是三个字符串起来的。理解了这一层，再回头看字符串的三种写法，就觉得顺理成章了——它本来就是一串字符排成的队。

## 转义字符：让引号只是引号

写英文的时候经常会有缩写，比如 `it's very good`。这句话用单引号定义，会很自然地写成：

```python
msg = 'it's very good'
```

一敲完就发现问题了：中间那个单引号把字符串提前截断了。它和开头那个单引号配成了一对，`'it'` 成了一个完整的字符串，后面剩下的 `s very good'` 就成了多余的东西，直接报错。

也就是说，用单引号定义的字符串里，不能再出现单引号——它会被当成结束符。

那字符串里就是想出现引号怎么办？两条路。

第一条路是**转义**：在引号前面加一个反斜杠。

```python
msg = 'it\'s very good'
print(msg)     # it's very good
```

反斜杠的作用是告诉 Python：后面这个引号只是引号本身，不是字符串的开始或结尾。加上它，代码不报错了，打印出来 `it's` 里的那个撇号也正常显示。

第二条路更省事：**外层换一种引号**。里面用单引号，外面就用双引号。

```python
msg = "it's very good"
```

外层是双引号，内层那个单引号就找不到可配对的伙伴了，自然被当成普通字符。

同样的道理反过来也成立：双引号字符串里要出现双引号，要么 `\"` 转义，要么外层换成单引号。

```python
msg3 = "我想强调\"您好\"这两个字"
msg4 = '我想强调"您好"这两个字'
```

两句打印出来是一样的效果。`msg3` 靠反斜杠把里面的双引号"救"出来，`msg4` 干脆换了个外壳。

常见的转义字符就四个：

| 转义字符 | 含义 |
| :--- | :--- |
| `\'` | 单引号本身 |
| `\"` | 双引号本身 |
| `\n` | 换行符 |
| `\t` | 制表符，相当于按一下 Tab 键 |

前两个解决引号冲突，后两个解决排版问题，用法完全不同。

`\n` 是换行。注意它的换行发生在**输出的时候**：源码里它还是一行，打印出来才断开。

```python
print("人生苦短，我用 Python！\n\t欢迎\n\t大家")
```

输出：

```text
人生苦短，我用 Python！
	欢迎
	大家
```

这句话源码里写的是一整行——毕竟双引号字符串不能换行——但打印出来是规规矩矩的三行，后两行还带着缩进。`\n` 正好补上了单双引号字符串"不能跨行"的短板：源码一行，输出多行。

`\t` 是制表符，也就是键盘上那个 Tab 键，作用是缩进对齐。上面两个 `\t` 分别加在"欢迎"和"大家"前面，输出时这两行就都往里退了一格。

> **注意**：缩进是给**输出内容**用的，不是给代码用的。现在这个阶段，我们的代码一律顶格写，不要随手缩进。想要打印出来的文字带缩进，就在字符串里写 `\t`，别去动代码本身的缩进。

## 字符串拼接：相邻即合并，加号连两段

很多时候我们手里有好几段文字，需要把它们合成一句完整的话，这就是字符串拼接。

如果几段都是字符串字面量，最简单的办法是直接并排写：

```python
s = "人生苦短" "我用Python"
print(s)     # 人生苦短我用Python
```

中间加不加空格、加几个空格，都不影响结果——解释器只认引号，不认空白。它在执行的时候会自动把这些相邻的字面量合并成一个字符串。

不过这种写法知道一下就行了。既然都是写死的字面量，为什么不干脆写成一个 `"人生苦短我用Python"`？一行就完事，还省得数引号。它真正的价值是让你明白：解释器会把相邻的字符串自动接起来。

真正在项目里用的是加号：把各个部分两两用 `+` 连起来，字面量、变量、标点，谁都可以参与。

```python
msg1 = "人生苦短"
msg2 = "我用Python"
print("Python之父吉多·范罗苏姆说：" + msg1 + "，" + msg2)
```

输出：

```text
Python之父吉多·范罗苏姆说：人生苦短，我用Python
```

这里每一个部分都是一段独立的字符串：`"Python之父吉多·范罗苏姆说："` 是字面量，`msg1` 是变量，`"，"` 也是一个字面量，`msg2` 又是变量。段与段之间必须有一个加号把它们连起来，缺一个就接不上。想要逗号后面多一个空格，就在那个逗号字符串里补一个空格。

而这条规则里最要紧的一条是：**加号只能拼接字符串和字符串**。

```text
"今年" + 18          ✗   左边是 str，右边是 int
"今年" + str(18)     ✓   两边都是 str，拼接成功
```

非字符串想参与拼接，必须先转成字符串。这个坑下一个案例里马上就会踩到。

## 案例：把自己的信息拼成一句话

需求是这样的：按自己的实际情况输出一段自我介绍，格式固定为——大家好，我是谁谁谁，今年多少岁，学习的专业是什么，爱好是什么。

这句话不能写死。名字每个人都不一样，年龄会变，专业和爱好也各不相同。凡是会变的部分，就用变量存起来，最后再拼成一句话。这也是字符串拼接在项目里真正被用到的场景：拼的从来不是两段写死的文字，而是固定文字和变量。

```python
name = "涛哥"
age = 18
pro = "软件工程"
hobby = "Python、Java"
```

变量名要有意义：名字叫 `name`，年龄叫 `age`，专业简写成 `pro`，爱好叫 `hobby`。一眼看过去就知道每个变量装的是什么。

第一版直接拼：

```python
print("大家好，我是" + name + "，今年" + age + "岁，学习的专业是" + pro + "，爱好是" + hobby)
```

还没运行，PyCharm 就先给了提示：`age` 这个词上有一片黄色背景。黄色背景是警告，不是报错，但它在提醒你这段代码可能有问题。把提示展开看，大意是——这个位置意外地出现了一个 `int` 类型，而它期望的是 `str` 类型。

也就是说，加号在这里等的是字符串，你塞过去一个整数。

非要运行也行，结果是直接报错。原因就是前面那句：加号只能拼接字符串，`18` 是 `int`，没资格站到加号旁边。

办法是转换。用 `str()` 把整数变成字符串：

```python
print("大家好，我是" + name + "，今年" + str(age) + "岁，学习的专业是" + pro + "，爱好是" + hobby)
```

再运行，输出：

```text
大家好，我是涛哥，今年18岁，学习的专业是软件工程，爱好是Python、Java
```

`str()` 也是一个内置工具，用法和 `type()`、`isinstance()` 一脉相承：名字后面跟一对小括号，括号里放要处理的数据。它把 `18` 这个整数变成 `"18"` 这个字符串——数值没变，类型变了，转换之后它才够格被加号连起来。

回头看这一篇，三条纪律值得记牢：变量本身没有类型，有类型的是它装着的那份数据；单引号和双引号定义的字符串不能跨行，要跨行就用三引号或者拼接；加号只认字符串，碰上数字先 `str()` 一下。
