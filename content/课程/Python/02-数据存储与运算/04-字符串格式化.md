# 字符串格式化

### 百分号占位

* **占位符（placeholder）**

* > **定义**：字符串里预留出来、等待被变量值顶替的位置标记。

* `%s` 中 `%` 表示占住这个位置，`s` 是 string 的简写，表示填进来的东西按字符串处理；`%` 与 `s` 必须紧挨，中间不能有空格。

* 运行时变量值会顶替掉 `%s` 那个位置，不是接在字符串后面。

* `%s` 会自动把整数、小数转成字符串再填，年龄这类数字变量不必手动 `str()`。

```python
name = "涛哥"
print("大家好，我是%s，欢迎大家进入到Python课程的学习" % name)
```

* **多占位符对位（positional matching）**

* > **定义**：字符串里有几个占位符，末尾 `%` 后的括号里就给几个数据，按先后顺序一一对应。

* 写法：字符串末尾用 `%` 引出括号，括号内用逗号分隔各个数据。

* 第一个值填第一个占位符，第二个值填第二个，依次往下，不能插队。

* 有几个 `%s` 就要给几个数据，一个不能多、一个不能少。

```python
name = "涛哥"
age = 18
print("大家好，我是%s，我今年%s岁" % (name, age))
```

* > **易错点**：变量一多，末尾括号里的顺序最容易和占位符对不上，填错位置不会报错，但输出会张冠李戴。

### f 字符串

* **f 字符串（f-string）**

* > **定义**：在字符串引号前加 `f`、用 `{}` 占位的格式化写法。

* `f` 是这套写法的开关：没有它，`{}` 只是一对普通符号。

* `{}` 里直接写变量名，写谁的名字就填谁的值，不存在按顺序对位的问题。

```python
name = "涛哥"
age = 18
print(f"大家好，我是{name}，我今年{age}岁")
```

* 与百分号写法相比，不用在字符串末尾再补 `%` 和一对括号重新列一遍变量。

* > **易错点**：漏写引号前的 `f`，`{name}` 不再被替换，会原样打印成 `{name}` 这几个字符。

* **表达式占位（expression placeholder）**

* > **定义**：f 字符串的大括号里除了变量名，还可以直接写算式。

* `f"取款后银行卡的余额为{total - int(number)}元"`：不必先算好存进一个变量，直接算、直接打印。

* 大括号里出现的是变量的组合运算时，结果按运算后的值填进那个位置。

### 两种写法对比

* **字符串格式化（string formatting）**

* > **定义**：先在字符串里把位置留出来、再把变量值填进去的拼接方式。

| 对比项 | 百分号占位 | f 字符串 |
| :--- | :--- | :--- |
| 占位符写法 | `%s` | `{}` |
| 变量写在哪儿 | 字符串末尾 `%` 之后，按顺序排列 | 直接写进大括号里 |
| 顺序要求 | 严格按占位符先后对位 | 写谁的名字就填谁的值 |
| 变量多时的观感 | 末尾一长串括号，来回对位 | 变量嵌在句子里，一眼看清 |

* 格式化与拼接的关系：本质仍是拼接，只是不再用加号连接，而是先占位再填值。

* **推荐写法（recommended style）**

* > **定义**：在百分号占位与 f 字符串之间挑一种写法落地。

* f 字符串更简洁，是现在企业开发里的推荐方式。

* 变量越多，两者的差距越明显：百分号写法要数占位符、核顺序，f 写法写完字符串这句代码就结束了。
