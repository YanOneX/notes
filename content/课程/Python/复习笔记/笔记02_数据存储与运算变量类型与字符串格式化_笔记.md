# 数据存储与运算：变量、类型与字符串格式化

## 变量

### 变量与赋值

* **变量（variable）**

    * > **定义**：程序中用来存储单个数据的容器。

    * 一个变量只装一个数据；通过变量名找到容器，再取出容器里当前存放的值。

    * 容器里的数据可以更换，容器本身始终是同一个；数据换了，仍然用原来的名字取用。

    * > **易错点**：变量指的是容器，不是容器里装的数据；`print(number)` 打印的是容器里的值，不是 `number` 这串字母。

* **赋值运算符（assignment operator）**

    * > **定义**：等号 `=`，把右侧算出的值赋给左侧的变量。

    * 语法是 `变量名 = 变量值`：等号左边是容器名，右边是要放进去的数据。

    * 定义变量与给变量赋值是同一件事，没有"只写名字、先不给值"的写法；变量必须先赋值后使用，否则解释器报该名字未定义。

    * > **提示**：`number = 1114.1` 读作"把 1114.1 交给 number"，不读"number 等于 1114.1"。

    ```python
    number = 1114.2
    print(number)        # 1114.2
    number = number + 1
    print(number)        # 1115.2
    ```

    * > **注意**：`number = number + 1` 在数学里不成立，在程序里合法：先取出右边的旧值参与运算，再把结果写回左边，先后顺序不能颠倒。

* **动态类型（dynamic typing）**

    * > **定义**：定义变量时不指定类型，运行时由解释器自动识别类型并做类型检查。

    * 同一个变量可以先后装不同类型的数据：`1114.1`（float）、`"OK"`（str）、`True`（bool），三次赋值都不报错。

    * > **易错点**：语言允许换类型，项目开发中推荐一个变量只存一种类型；名字既已规划为存播放量的小数，就不要再拿它装字符串或布尔值。

### 标识符与命名

* **标识符（identifier）**

    * > **定义**：给变量、函数、类等元素起的名字；当前阶段用到的就是变量名。

    * 规则是硬性规定，违反则程序跑不起来。

    | 规则 | 内容 |
    | :--- | :--- |
    | 组成 | 只能包含字母、数字、下划线，符号只认 `_` |
    | 开头 | 不能以数字开头，下划线可以开头 |
    | 关键字 | 不能使用 Python 的关键字 |
    | 大小写 | 严格区分大小写 |

    * 合法示例：`name`、`Name`、`_name`、`__name`、`na_me`、`name_`、`name6`、`nameME`、`true`。

    * 非法示例：`na$me`（含 `$`）、`6name`（数字开头）、`and`、`or`、`True`、`False`（关键字）。

    * > **提示**：规则记不牢时，把名字敲进编辑器跑一遍——能正常运行就是合法，跑不起来就是非法。

* **关键字（keyword）**

    * > **定义**：语言保留自用的词，被占用后不能再拿来当变量名。

    * 常见关键字：`True`、`False`、`and`、`or`、`if`、`else`、`for`、`while`。

    * `True`、`False` 是布尔字面量；`and`、`or` 用于逻辑运算；`if`、`else`、`for`、`while` 用于流程控制。

    * > **易错点**：关键字是首字母大写的 `True`、`False`；全小写的 `true`、`false` 与它们大小写不同，不是关键字，可以当变量名使用。

* **PEP 8**

    * > **定义**：Python 社区描述代码风格与编码规范的技术文档，对变量名给出三条建议。

    | 规范 | 做法 | 反例 |
    | :--- | :--- | :--- |
    | 见名知意 | 名字能说明里面存的是什么 | `a1`、`a2`、`a3` |
    | 下划线连接 | `update_time`、`my_name`、`user_first_name` | `updatetime`、`myname` |
    | 全小写 | 变量名里不出现大写字母 | `Name`、`UserName` |

    * > **注意**：规范不是规定，不符合规范程序照样运行，官方只是建议这么写。

* **蛇形命名法（snake_case）**

    * > **定义**：多个单词之间用下划线连接、整体看上去像一条蛇的命名写法。

    * 例如 `update_time`、`my_name`、`user_first_name`，每两个相邻的单词之间都有一个下划线。

    * 这套写法只管变量名，其他元素（比如类）各有各的写法，不要混用。

### 多变量赋值与交换

* **同时定义多个变量（multiple assignment）**

    * > **定义**：一行内用逗号分隔变量名与值，按位置一一对应地赋值。

    * `base, incr = 20.7, 50` 与分两行定义效果完全相同。

    * > **易错点**：位置对应不能乱；写成 `base, incr = 50, 20.7` 不会报错，但两个变量拿到的值正好相反，算出来的结果会离谱。

* **临时变量（temporary variable）**

    * > **定义**：为暂存某个变量被覆盖前的旧值而引入的第三个变量。

    * 交换 `a`、`b` 需要三步：`c = a` 寄存、`a = b` 覆盖、`b = c` 取回。

    ```python
    a = 10
    b = 20

    c = a
    a = b
    b = c

    print(a, b)      # 20 10
    ```

    * 只写 `a = b`、`b = a` 会得到两个 20：第一行覆盖掉 `a` 的 10，第二行取到的已经是 `a` 的新值。

    * > **易错点**：第三步必须写 `b = c`，不能写 `b = a`；走到第三步时 `a` 已经被改成 20。

    * 三变量轮换同理：先寄存 `a`，再依次 `a = b`、`b = c`、`c = 临时变量`，得到 `a = 200`、`b = 300`、`c = 100`。

## 数据类型

### 五种基础类型

* **基础数据类型（basic data types）**

    * > **定义**：Python 中最常用的一组内置数据类型，共五种。

    | 类型 | 名称 | 说明 | 例子 |
    | :--- | :--- | :--- | :--- |
    | `int` | 整数 | 正整数、负整数、零 | `10`、`-100`、`0` |
    | `float` | 浮点数 | 带小数点的小数，不分正负 | `8.5`、`3.14`、`-3.5` |
    | `str` | 字符串 | 描述文本，必须用引号引起来 | `"hello"`、`'Python'` |
    | `bool` | 布尔 | 真或假，只有两个值 | `True`、`False` |
    | `NoneType` | 空值 | 只有一个值，表示没有值 | `None` |

    * 辨认方式：看到 `3.14` 想到 `float`，看到引号包着的想到 `str`，看到 `True`、`False` 想到 `bool`，看到 `None` 想到 `NoneType`。

    * 空值类型的含义是这个位置为空、或者说没有值。

* **值的类型（type of value）**

    * > **定义**：变量本身没有类型，变量里存的那个数据才有类型。

    * 变量是容器，容器本身不分类；往容器里放什么，容器里的东西才分类型。

    * `type(number)` 盯着的是容器里那个值，变量名只是一个门牌号。

### 类型查看与判断

* **type()**

    * > **定义**：内置工具，返回括号内数据的类型，写法为 `type(要查的数据)`。

    * `type("hello")` 得 `<class 'str'>`，`type(10)` 得 `<class 'int'>`，`type(3.14)` 得 `<class 'float'>`，`type(None)` 得 `<class 'NoneType'>`。

    * `class` 在这里就是"类型"的意思，`str` 是 string 的缩写。

    * `type` 只负责查，不负责显示；要看到结果必须再包一层 `print`。

    * > **易错点**：`type(变量)` 打印的是值所属的类型，不是"变量被声明成的类型"——Python 定义变量时根本没有声明类型这一步。

* **isinstance()**

    * > **定义**：判断某个数据是否属于指定类型，返回布尔值，写法为 `isinstance(数据, 类型)`。

    * `isinstance(-100, int)` 得 `True`，`isinstance(-100, float)` 得 `False`，`isinstance(-100, bool)` 得 `False`。

    * 想"看一眼是什么"用 `type`，想"验证是不是"用 `isinstance`；两者都能用在字面量和变量上。

### 类型转换

* **类型转换（type conversion）**

    * > **定义**：用内置函数把数据从一种类型转成另一种类型。

    | 工具 | 作用 |
    | :--- | :--- |
    | `int()` | 转成整数类型 |
    | `float()` | 转成浮点数类型 |
    | `str()` | 转成字符串类型 |
    | `bool()` | 转成布尔类型 |

    * `str(18)` 把整数变成 `"18"`：数值没变，类型变了，转换之后才有资格参与字符串拼接。

    * `bool()` 目前没有使用场景，知道有这么一个工具即可。

* **数值解析（numeric parsing）**

    * > **定义**：`int()` 按整数写法解析，`float()` 按小数写法解析，两者接受的输入范围不同。

    * `int("1000")` 得 1000；`int("10.5")` 直接报错，因为 `10.5` 不是合法的整数字面量。

    * 要处理小数就换 `float()`：`float("10.5")` 得 10.5。

    * > **易错点**：题目只说"两个数"而没有限定整数时，用 `int()` 会挡住小数输入，应改用 `float()`。

## 字符串

### 定义方式

* **引号字符串（quoted string）**

    * > **定义**：用一对单引号或一对双引号包住文本的写法，两者完全等价。

    * `s1 = "hello"`、`s2 = 'Python'`，用 `type` 查出来都是 `<class 'str'>`。

    * 两者都不能直接换行；在引号中间敲回车，编辑器会把它拆成两个字符串再自动拼回去。

    * 同一个项目里要么统一用双引号、要么统一用单引号，不要混着写。

* **三引号字符串（triple-quoted string）**

    * > **定义**：用三个单引号或三个双引号包住文本的写法，支持换行且原样保留格式。

    * 官方推荐用三个双引号；开头的引号之后先换行，打印出来的第一行就是空的。

    * 换行与 Tab 缩进都原样输出；它后面还有一个用途是写文档注释。

    ```python
    s3 = """
    hello
        欢迎大家进入到 Python 课程的学习
    """
    print(s3)
    ```

    * > **易错点**：把 `# 这是注释` 写进三引号内部，它就不再是注释，而是字符串内容的一部分，会跟着原样打印。

* **字符（character）**

    * > **定义**：字符串里的每一个字母、汉字、符号、数字都是一个字符，字符是组成字符串的基本单位。

    * `"hello"` 是五个字符串起来的，`"你好"` 是两个字符串起来的。

    * "字符串"这个名字的来源就是把多个字符"串"在一起。

### 转义字符

* **转义字符（escape character）**

    * > **定义**：以反斜杠开头的特殊写法，告诉 Python 后面这个字符只按字面意思解释。

    | 转义字符 | 含义 |
    | :--- | :--- |
    | `\'` | 单引号本身 |
    | `\"` | 双引号本身 |
    | `\n` | 换行符 |
    | `\t` | 制表符，相当于按一下 Tab 键 |

    * `\n` 的换行发生在输出时：源码里还是一行，打印出来才断开。

    * `\t` 的作用是缩进对齐，加在文字前面，输出时该行就往里退一格。

    ```python
    print("人生苦短，我用 Python！\n\t欢迎\n\t大家")
    ```

    * > **注意**：缩进是给输出内容用的，不是给代码用的；代码一律顶格写，要让打印的文字带缩进就写 `\t`。

* **引号冲突（quote conflict）**

    * > **定义**：用单引号定义字符串时，内容里再出现单引号会被当成结束符，字符串被提前截断。

    * `'it's very good'` 中第二个单引号与开头那个配成一对，`'it'` 成了完整字符串，剩下的 `s very good'` 变成多余内容并报错。

    * 第一条解法是转义：`'it\'s very good'`，反斜杠让这个引号只当引号本身。

    * 第二条解法更省事：外层换一种引号，`"it's very good"` 里的单引号找不到配对的伙伴，自然成了普通字符；双引号字符串里要出现双引号时同理，用 `\"` 或外层换单引号。

### 拼接

* **相邻字面量合并（implicit concatenation）**

    * > **定义**：并排写在一起的多个字符串字面量，解释器执行时自动合并成一个字符串。

    * `"人生苦短" "我用Python"` 得到 `人生苦短我用Python`；中间加不加空格、加几个都不影响结果。

    * 解释器只认引号、不认空白；既然都是写死的字面量，不如直接写成一整句。

* **加号拼接（string concatenation）**

    * > **定义**：用 `+` 把字面量、变量、标点连接成一个字符串。

    * `"Python之父吉多·范罗苏姆说：" + msg1 + "，" + msg2`，段与段之间必须有加号，缺一个就接不上。

    * 加号只能拼接字符串与字符串：`"今年" + 18` 报错，`"今年" + str(18)` 才成立。

    * 三处不顺手：每两段之间补一个加号；引号、加号、变量名混在一起，代码里读不出一整句话；数字要先 `str()` 转换。

    * > **易错点**：两个 `input` 得到的字符串相加是拼接不是求和，`"10" + "5"` 得 `"105"`；相减则直接报类型错误。

## 字符串格式化

### 百分号占位

* **占位符（placeholder）**

    * > **定义**：字符串里预留出来、等待被变量值顶替的位置标记。

    * `%s` 中 `%` 表示占住这个位置，`s` 是 string 的简写，表示填进来的东西按字符串处理；`%` 与 `s` 必须紧挨，中间不能有空格。

    * 运行时变量值会顶替掉 `%s` 那个位置，不是接在字符串后面。

    * `%s` 会自动把整数、小数转成字符串再填，年龄这类数字变量不必手动 `str()`。

    ```python
    name = "涛哥"
    print("大家好，我是%s，欢迎大家进入到Python课程的学习" % name)
    ```

* **多占位符对位（positional matching）**

    * > **定义**：字符串里有几个占位符，末尾 `%` 后的括号里就给几个数据，按先后顺序一一对应。

    * 写法：字符串末尾用 `%` 引出括号，括号内用逗号分隔各个数据。

    * 第一个值填第一个占位符，第二个值填第二个，依次往下，不能插队。

    * 有几个 `%s` 就要给几个数据，一个不能多、一个不能少。

    ```python
    name = "涛哥"
    age = 18
    print("大家好，我是%s，我今年%s岁" % (name, age))
    ```

    * > **易错点**：变量一多，末尾括号里的顺序最容易和占位符对不上，填错位置不会报错，但输出会张冠李戴。

### f 字符串

* **f 字符串（f-string）**

    * > **定义**：在字符串引号前加 `f`、用 `{}` 占位的格式化写法。

    * `f` 是这套写法的开关：没有它，`{}` 只是一对普通符号。

    * `{}` 里直接写变量名，写谁的名字就填谁的值，不存在按顺序对位的问题。

    ```python
    name = "涛哥"
    age = 18
    print(f"大家好，我是{name}，我今年{age}岁")
    ```

    * 与百分号写法相比，不用在字符串末尾再补 `%` 和一对括号重新列一遍变量。

    * > **易错点**：漏写引号前的 `f`，`{name}` 不再被替换，会原样打印成 `{name}` 这几个字符。

* **表达式占位（expression placeholder）**

    * > **定义**：f 字符串的大括号里除了变量名，还可以直接写算式。

    * `f"取款后银行卡的余额为{total - int(number)}元"`：不必先算好存进一个变量，直接算、直接打印。

    * 大括号里出现的是变量的组合运算时，结果按运算后的值填进那个位置。

### 两种写法对比

* **字符串格式化（string formatting）**

    * > **定义**：先在字符串里把位置留出来、再把变量值填进去的拼接方式。

    | 对比项 | 百分号占位 | f 字符串 |
    | :--- | :--- | :--- |
    | 占位符写法 | `%s` | `{}` |
    | 变量写在哪儿 | 字符串末尾 `%` 之后，按顺序排列 | 直接写进大括号里 |
    | 顺序要求 | 严格按占位符先后对位 | 写谁的名字就填谁的值 |
    | 变量多时的观感 | 末尾一长串括号，来回对位 | 变量嵌在句子里，一眼看清 |

    * 格式化与拼接的关系：本质仍是拼接，只是不再用加号连接，而是先占位再填值。

* **推荐写法（recommended style）**

    * > **定义**：在百分号占位与 f 字符串之间挑一种写法落地。

    * f 字符串更简洁，是现在企业开发里的推荐方式。

    * 变量越多，两者的差距越明显：百分号写法要数占位符、核顺序，f 写法写完字符串这句代码就结束了。

## 键盘输入

### input 的调用

* **input()**

    * > **定义**：Python 内置的输入功能，把键盘录入的内容接进程序并赋给变量。

    * 执行到这一行时，括号里的提示信息先打印到控制台，然后程序停住等键盘，按下回车才继续往下走。

    * 两个 `input` 是两步：姓名输完回车，才会轮到问年龄。

    * 提示信息末尾习惯加一个冒号，光标紧跟在冒号后面，输入位置一目了然。

    ```python
    name = input("请输入您的姓名：")
    age = input("请输入您的年龄：")
    print(f"您的姓名是{name}，年龄为{age}")
    ```

* **输入值的类型（input type）**

    * > **定义**：`input()` 取回来的数据永远是字符串，与敲进去的内容长什么样无关。

    * 敲 `18` 得到 `"18"`，敲 `3.14` 得到 `"3.14"`，敲字母得到的还是字符串。

    * `input` 不猜你想要什么类型，只负责把键盘上的字符原样搬进程序。

    * > **易错点**：`"18"` 与 `18` 是两种东西，前者不能参与算术运算；凡是要拿来算的输入，必须先转换类型。

### 输入数据的转换

* **嵌套转换（nested conversion）**

    * > **定义**：把 `input()` 直接套进转换函数，一行完成取值与转类型。

    * `int(input("请输入X的值："))`：先取回字符串，再当场转成整数。

    * 用 `int` 版输入 10 和 5，和是 `15`、差是 `5`，都是算出来的。

    * `float(input("请输入X的值："))` 更通用，整数小数都收；代价是整数结果也带小数点，10 变 `10.0`、和变成 `15.0`。

    * 输入 `0.5` 时 `int` 版解析失败报错，`float` 版能继续算下去。

* **浮点数精度损失（floating-point precision loss）**

    * > **定义**：二进制无法精确表示所有小数，写进内存的已经是近似值，运算之后误差就露到明面上。

    * `0.5 - 0.4` 的结果不是 `0.1`，而是 `0.09999999999999998`；`0.5 + 0.4` 则是 `0.9`。

    * 凡是涉及浮点数的运算都可能出现精度损失，原因在计算机的二进制存储方式，不在 Python。

    * > **注意**：这属于计算机做算术运算时的正常情况，不是异常；`0.1 + 0.2` 不等于 `0.3` 时不必怀疑代码写错。

## 运算符

### 算术运算符

* **算术运算符（arithmetic operator）**

    * > **定义**：作用在一个或多个数字上、产生一个数值结果的符号，共七个。

    | 运算符 | 名称 | 示例 | 结果 |
    | :---: | :--- | :--- | :--- |
    | `+` | 加 | `10 + 4` | `14` |
    | `-` | 减 | `10 - 4` | `6` |
    | `*` | 乘 | `10 * 4` | `40` |
    | `/` | 除 | `10 / 4` | `2.5` |
    | `//` | 整除 | `10 // 4` | `2` |
    | `%` | 取余 | `10 % 4` | `2` |
    | `**` | 幂指数 | `10 ** 4` | `10000` |

    * 乘法用星号 `*`，除法用斜杠 `/`，与课本上的 `×`、`÷` 写法不同。

    * 除法 `/` 的结果一定是浮点数：`10 / 5` 得 `2.0`，`10 / 4` 得 `2.5`，除得尽也不例外。

    * 整除 `//` 只保留整数部分，`10 // 3` 得 3；取余 `%` 留下余数，`10 % 3` 得 1。

    * 幂指数 `**`：`10 ** 3` 得 1000，`4 ** 2` 得 16；10 的幂指数是几，后面就跟几个 0。

    ```python
    print(10 + 4)     # 14
    print(10 - 4)     # 6
    print(10 * 4)     # 40
    print(10 / 4)     # 2.5
    print(10 // 4)    # 2
    print(10 % 4)     # 2
    print(10 ** 4)    # 10000
    ```

    * > **易错点**：`10 // 4` 与 `10 % 4` 都得 2 纯属巧合；一个给整数商、一个给余数，两个符号别记混。

* **运算符优先级（operator precedence）**

    * > **定义**：一个式子里同时出现多个运算符时，决定先算谁的顺序。

    | 优先级 | 运算符 |
    | :---: | :--- |
    | 最高 | `**` |
    | 次之 | `*`、`/`、`//`、`%` |
    | 最低 | `+`、`-` |

    * `0.1 + 10 / 4 ** 2` 按优先级分三步：$4^2 = 16$、$10 \div 16 = 0.625$、$0.1 + 0.625 = 0.725$。

    * 括号的优先级最高，想让 `0.1 + 10` 先算，把它们括起来即可。

### 赋值运算符

* **简单赋值（simple assignment）**

    * > **定义**：为变量做赋值操作的符号，一个等号 `=` 是最基础、用得最多的一个。

    * `number = 1 + 2` 先算出 3，再把 3 交给 `number`。

    * `=` 读作"把右边赋给左边"，不读"等于"；数学里的"等于"在 Python 里要写成 `==`。

* **复合赋值运算符（augmented assignment）**

    * > **定义**：在变量原值上做一次算术运算、再把结果存回该变量自身的简写符号。

    | 运算符 | 写法示例 | 完全等效于 |
    | :--- | :--- | :--- |
    | `+=` | `number += 2` | `number = number + 2` |
    | `-=` | `number -= 2` | `number = number - 2` |
    | `*=` | `number *= 2` | `number = number * 2` |
    | `/=` | `number /= 2` | `number = number / 2` |
    | `//=` | `number //= 2` | `number = number // 2` |
    | `%=` | `number %= 2` | `number = number % 2` |
    | `**=` | `number **= 2` | `number = number ** 2` |

    * `number = 3` 后执行 `number += 2`，三步：取出 3、与 2 相加得 5、把 5 写回 `number`。

    * 右边不是"另一个变量"，而是"我自己现在是多少"，所以同一句连着写两遍，值会在上一次结果上继续叠。

    * 从 85 出发依次执行 `+= 10` 到 `**= 3`，结果依次为 `95`、`85`、`850`、`85.0`、`8.0`、`2.0`、`8.0`。

    * > **易错点**：`+=`、`**=` 本质是一个符号，中间不能加空格或其他字符；`number + = 2`、`number ** = 2` 都是错的。

    * > **注意**：算术运算里有浮点数参与，结果就是浮点数；那串 `.0` 来自 `number /= 10` 那一句，不是 `//=`、`%=`、`**=` 自带的。

### 比较运算符

* **比较运算符（comparison operator）**

    * > **定义**：比较两个值之间关系的符号，运算结果一定是布尔值。

    | 运算符 | 读法 | 示例 | 什么时候是 True |
    | :--- | :--- | :--- | :--- |
    | `==` | 等于 | `a == b` | a 与 b 的值相等 |
    | `!=` | 不等于 | `a != b` | a 与 b 的值不相等 |
    | `>` | 大于 | `a > b` | a 比 b 大 |
    | `>=` | 大于等于 | `a >= b` | a 比 b 大，或与 b 相等 |
    | `<` | 小于 | `a < b` | a 比 b 小 |
    | `<=` | 小于等于 | `a <= b` | a 比 b 小，或与 b 相等 |

    * `==` 是两个等号，一个等号是赋值；`!=` 的叹号与等号之间不能有空格。

    * 数学里的 $\ge$、$\le$ 键盘上打不出来，编程里写成大于号或小于号后接等号。

    * `100 >= 100` 得 `True`，`100 > 100` 得 `False`，`100 <= 100` 得 `True`。

    * `"100" == "100"` 同样得 `True`：两个字符串值完全一致。

    * > **易错点**：`==` 与 `=` 别混，一个比较、一个赋值。

* **链式比较（chained comparison）**

    * > **定义**：像 `10 <= number <= 20` 这样连着写的比较，等价于两个条件同时成立。

    * 与 `number >= 10 and number <= 20` 效果完全相同，写法和数学里的 $10 \le number \le 20$ 一样。

    * 更短也更好读，实际开发里推荐使用。

* **条件表达式（condition）**

    * > **定义**：由比较运算符组成、结果为布尔值的表达式，用来把一句业务需求翻译成判断。

    * 判断偶数：`number % 2 == 0`，先对 2 取余，再判断余数是否等于 0。

    * 余额充足：`balance >= price`；库存足够：`stock >= count`；不超过 100 元：`price <= 100`。

    * > **易错点**：判断偶数这道题问的是比较运算符，答案落在 `==` 上；取余 `%` 是算术运算符的活，别答错层。

### 逻辑运算符

* **逻辑运算符（logical operator）**

    * > **定义**：连接多个条件表达式的符号，运算结果同样是布尔值，表示这些条件最终到底成不成立。

    | 运算符 | 名称 | 含义 | 结果规则 |
    | :--- | :--- | :--- | :--- |
    | `and` | 逻辑与 | 并且 | 两侧都 `True` 才 `True` |
    | `or` | 逻辑或 | 或者 | 有一侧 `True` 就 `True` |
    | `not` | 逻辑非 | 取反 | `True` 变 `False`，`False` 变 `True` |

* **逻辑与（AND）**

    * > **定义**：两侧条件都为 `True` 时结果才是 `True`，相当于"并且"。

    | 左侧 | 右侧 | 结果 |
    | :--- | :--- | :--- |
    | `True` | `True` | `True` |
    | `True` | `False` | `False` |
    | `False` | `True` | `False` |
    | `False` | `False` | `False` |

    * `number >= 10 and number <= 20` 判断数字是否在 10 到 20 之间：两侧同时成立才是 `True`。

    * 输入 5 得 `False`（左侧不成立），输入 15 得 `True`，输入 60 得 `False`（右侧不成立）。

* **逻辑或（OR）**

    * > **定义**：两侧条件只要有一个 `True` 结果就是 `True`，相当于"或者"。

    | 左侧 | 右侧 | 结果 |
    | :--- | :--- | :--- |
    | `True` | `True` | `True` |
    | `True` | `False` | `True` |
    | `False` | `True` | `True` |
    | `False` | `False` | `False` |

    * `number < 10 or number > 20` 判断数字是否不在 10 到 20 之间：整条数轴被切成三段，落在左右任意一段就成立。

    * 输入 1 得 `True`，输入 15 得 `False`（两个条件都不成立），输入 56 得 `True`。

* **逻辑非（NOT）**

    * > **定义**：对布尔值取反，`True` 取反是 `False`，`False` 取反是 `True`。

    * 只做取反这一件事，与 `and`、`or` 一起构成三个逻辑运算符。

* **复合条件（compound condition）**

    * > **定义**：把多个业务条件用逻辑运算符连成一个结论。

    * 登录成功要求用户名正确 `and` 密码正确，两者必须同时成立。

    * 扫码、密码、短信三种登录方式之间是"采用其中一种即可"，用 `or` 连接。
