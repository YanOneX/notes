# 计算机网络

> 这门课是仓库里的**示例课程**，用来说明目录长什么样、一篇精读长文该写到什么程度。
> 你换成自己的课程后可以直接删掉整个文件夹。

## 这门课在讲什么

一句话：**在不可靠的链路上，造出一个可靠的、够快的、能互联的通信系统。**

所有章节都在回答同一个问题在不同层次上的版本：

| 层次 | 它要解决的问题 | 典型手段 |
| --- | --- | --- |
| 链路层 | 两个相邻设备怎么把比特送对 | 成帧、CRC、重传 |
| 网络层 | 怎么从任意主机走到任意主机 | IP 寻址、路由 |
| 传输层 | 端到端怎么不丢不乱、还别把网络堵死 | 序号确认、滑动窗口、拥塞控制 |
| 应用层 | 具体业务怎么用上面的能力 | HTTP、DNS |
