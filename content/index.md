# 课程笔记

这是我用 AI 把课程视频（B 站合集 / YouTube 频道 / 抖音合集 / 本地录像）整理出来的笔记站点。
视频的信息密度很低：一小时的课，真正值得记下来的往往只有十几页。
这里的每篇笔记都按"合上书能自己复述一遍"的标准来写，而不是把字幕排个版。

## 三种读法

| 类型 | 是什么 | 什么时候看 |
| --- | --- | --- |
| 精读长文 | 一个知识块一篇，把一节课讲透 | 第一次学、补课 |
| 整编教材 | 把一门课串成有目录的书 | 系统复习、查漏补缺 |
| 复习笔记 | 跨模块的速记、易错点、公式表 | 考前、面试前 |

## 它是怎么做出来的

1. 把课程链接交给 [video2book](https://github.com/LINJIANG12/video2book)：它按 40–60 分钟切"知识块"，优先抓字幕，没有字幕才转录音频。
2. 每个知识块生成一篇精读长文，再把整门课整编成教材和跨模块复习笔记。
3. 笔记在 Obsidian 里改，用 [Quartz](https://quartz.jzhao.xyz/) 发布，推到 GitHub 之后自动构建成这个网站。

> [!note] 关于这个站
> 站点源码和笔记在同一个仓库里：`content/` 就是 Obsidian 库，其余是 Quartz 的构建代码。
> 想自己搭一个同样的站，照着仓库根目录的 `README.md` 做即可。
